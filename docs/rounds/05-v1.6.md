## 13. Fifth Exploration Round (v1.6): Proofs and Validation

### 13.1 The Stability Theorems

**Theorem L2 (μ-stability).** Let L be a complete lattice, F : L × L → L monotone, `a(x) = νY.F(x,Y)`, `b(y) = μX.F(X,y)`, `m = μ(a)`. Then `b(m) = m`.

*Proof.* (1) m is a-fixed, so `m = a(m) = F(m, a(m)) = F(m, m)`: m is a fixed point of `u_m : x ↦ F(x, m)`. (2) `b(m) = μ(u_m) ⊑ m`, since a least fixed point lies below every fixed point. (3) `F(b(m), m) = b(m)`, as `b(m)` is a fixed point of `u_m`. (4) From (2), `b(m) ⊑ m`, so monotonicity in the second argument gives `F(b(m), b(m)) ⊑ F(b(m), m) = b(m)`. (5) Hence `b(m)` is a pre-fixed point of `v_{b(m)} : y ↦ F(b(m), y)`; since the greatest fixed point is the infimum of pre-fixed points (Tarski), `a(b(m)) ⊑ b(m)`. (6) `b(m)` is now a-pre-fixed, so `m = μ(a) ⊑ b(m)`. Together with (2): `b(m) = m`. ∎

*Erratum (round 26, §34.1): step (5) misattributes Tarski. A pre-fixed point does not bound the gfp. Correct step: c = b(m) ≤ m gives a(c) ≤ a(m) = m, so a(c) = F(c, a(c)) ≤ F(c, m) = c. The L1 proof below likewise needs §34.1's direct argument. All three statements are machine-checked in `lean/Mordor/Derived.lean`.*

**Corollary I1 (lower commutation).** By L2, m is b-fixed, hence b-post-fixed, so `m ⊑ ν(b) = νY.μX.F(X,Y)`. Thus `μX.νY.F ⊑ νY.μX.F` for every monotone F on a complete lattice. ∎

**Corollary L1 (ν-stability).** n is a fixed point of `v_n` (since `b(n) = n` forces `F(n,n) = n`), so `n ⊑ a(n)` always. And `a(n) ⊑ n` ⟺ n is a-pre-fixed ⟺ `m ⊑ n` ⟺ I1. Hence `a(n) = n`. ∎

The framework's I1 interaction rule is thereby a genuine theorem of monotone bifunctors — no side conditions.

### 13.2 Exhaustive validation on the square lattice B2

All monotone bifunctions `B2 × B2 → B2` (28,224, via all pairs of the 168 monotone Boolean functions of 4 variables):

| Check | Failures |
|---|---|
| L1, L2 | 0 / 28,224 (as proven) |
| L3, L4 | **0 / 28,224** |
| I1 | 0 / 28,224 |
| Commutation ⟹ equality | 15,984 / 15,984 |
| `equality ⟺ μ(a∘b) = ν(a∘b)` | 0 failures |
| `equality ⟺ a(n) = m ∧ b(m) = n` | 0 failures |

L3, L4, the Commutation Lemma, and both exact characterizations now hold on two independent lattice families (chains and the square). L3/L4 admit a partial reduction: `μ(a∘b) = μ(a)` would follow if `μ(a∘b)` is b-post-fixed (then `a(μ(a∘b)) ⊑ μ(a∘b)` makes it a-pre-fixed, forcing `m ⊑ μ(a∘b)`; the reverse holds unconditionally). The remaining gap is exactly this post-fixedness.

### 13.3 Failure-zone predictors: a negative result

Conditioning the poset censuses on standard preservation invariants does not separate the iso zone from the failure zone — several invariants *anti*-correlate:

| Condition | Chain 4 iso rate | M3 iso rate |
|---|---|---|
| Baseline | 62.5% | 82.8% |
| F preserves bottom | 57.1% | 84.3% |
| F pointwise ⊑ G | **48.2%** | **65.8%** |
| F, G both join-preserving | 62.5% (vacuous) | **75.3%** |
| F preserves bottom ∧ G preserves top | 50.0% | 83.3% |

The dialgebra condition being *permissive* (F ⊑ G pointwise — every object carries a dialgebra) actively **hurts** iso-ness: the least solution sits at the bottom, where F and G most often disagree. δ₀ iso-ness is a *tightness* phenomenon, not a preservation phenomenon. No standard invariant predicts it; the (F, Id) boundary slice (100% iso) remains the only clean positive class. Problem #3 is answered negatively: the failure zone is genuinely structural.
