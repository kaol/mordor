## 14. Sixth Exploration Round (v1.7): L3/L4 Proven — the Characterization Theorem

### 14.1 Fixed-point fusion, and the proofs

**Proposition (Fixed-point fusion).** For any z: z is `(a∘b)`-fixed ⟺ z is a common fixed point of a and b. Hence **Fix(a∘b) = Fix(a) ∩ Fix(b)**, unconditionally.

*Proof.* (⟸) trivial. (⟹) Let `z = a(b(z))`. Fixed points of a satisfy `a(w) = F(w, a(w))`, so `z = a(b(z)) = F(b(z), z)`. Meanwhile `b(z)` is a fixed point of `u_z : x ↦ F(x, z)`: `b(z) = F(b(z), z)`. Both z and b(z) equal `F(b(z), z)`, so `z = b(z)`; then `a(z) = a(b(z)) = z`. ∎

**Theorem L3.** `μ(a∘b) = μ(a) = μX.νY.F`. *Proof.* Let `t = μ(a∘b)`. By fusion, t is a- and b-fixed, so the least a-fixed point satisfies `m ⊑ t`. Conversely m is `(a∘b)`-fixed (L2: `b(m) = m ⟹ a(b(m)) = a(m) = m`), so `t ⊑ m`. ∎

**Theorem L4.** `ν(a∘b) = ν(b) = νY.μX.F`. *Proof.* Let `s = ν(a∘b)`. By fusion, s is b-fixed, so `s ⊑ ν(b) = n`. Conversely n is common-fixed (L1 and `b(n) = n`), hence `(a∘b)`-fixed, so `n ⊑ s`. ∎

**Theorem (I2 characterization — full).** For monotone F on a complete lattice, the following are equivalent:

1. `νY.μX.F(X,Y) ⊑ μX.νY.F(X,Y)` (rule I2),
2. `μX.νY.F = νY.μX.F` (the sandwich Bd1 is tight),
3. `a∘b` has a unique fixed point,
4. a and b have exactly one common fixed point.

*Proof.* (1) ⟺ (2): I2 together with I1 (proven, §13). (2) ⟺ (4): m is the bottom of `Fix(a) ∩ Fix(b)` (m is common-fixed by L2, and m is below every a-fixed point) and n is its top (n is common-fixed by L1 and above every b-fixed point); a lattice-fragment's bottom equals its top iff it is a singleton. (3) ⟺ (4): fusion. ∎

The 20 finite-chain counterexamples of §11 are now fully explained: they are precisely the 20 bifunctions whose derived maps share more than one common fixed point (chain-3 census: 20 multi-common-fixed cases, zero of them equal).

### 14.2 The Commutation Lemma: final reduction

Under commutation `a∘b = b∘a`, the classical pairwise identities give `μ(a∘b) = μ(a) ∨ μ(b)` and `ν(a∘b) = ν(a) ∧ ν(b)`. With L3/L4 these yield `μ(b) ⊑ m` and `n = ν(b) ⊑ ν(a)`. If b has a unique fixed point p, then `n = ν(b) = p = μ(b) ⊑ m ⊑ n`, forcing `m = n`. Hence:

**Commutation Lemma ⟺ under commutation, the μ-step map b has a unique fixed point ⟺ a commuting derived pair has exactly one common fixed point.**

Stress test (diamond M3, 30,000 sampled monotone bifunctions): L1–L4 and I1 — zero failures (independent confirmation of the proofs); commutation ⟹ equality — **28,974/28,974**; commuting cases with multiple common fixed points — **zero**.

Cumulative validation of the lemma: **44,095 commuting cases across three lattice families (chain 3, square B2, diamond M3), zero failures.**
