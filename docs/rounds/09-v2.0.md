## 17. Ninth Exploration Round (v2.0): The Staircase Squeeze

### 17.1 The Staircase Squeeze Theorem

**Setting.** A polar configuration (§15.1) on the finite chain 0 ⊏ … ⊏ N — no commutation assumed. Recall the bands (§16.2(3)): `B = {y : F(0,y) = 0} = ↓β` and `T = {x : F(x,N) = N} = ↑τ`, both nontrivial. Note the band conditions have single-point readings: `a(B) ⊆ B ⟺ a(β) ⊑ β` (B is a downset and a is monotone) and `b(T) ⊆ T ⟺ b(τ) ⊒ τ`.

**Theorem (Squeeze, primal).** If `a(β) ⊑ β` and β ⊏ N, then `b(β+1) ⊑ β`.

*Proof.* Suppose `b(β+1) ≻ β`; put `j = β+1` and `g(x) = F(x,j)` (column j). Since the *least* fixed point of g exceeds β, g has **no fixed point** `x ⊑ β`; in particular `g(0) ≠ 0`, so `g(0) ≥ 1`. Monotone pigeonhole (g nondecreasing, `g(x) ≠ x` for `x ⊑ β`, `g(0) ≥ 1`): by induction `g(x+1) ≥ g(x) ≥ x+1` and `g(x+1) ≠ x+1` while `x+1 ⊑ β`, hence `g(x) ≥ x+1` for all `x ⊑ β`. So `F(β,j) ≥ j`. Now the row `f(y) = F(β,y)`: `a(β) ⊑ β` means f's greatest fixed point is ⊑ β, so f has no fixed point above β; `f(j) ≠ j` (j > β) with `f(j) ≥ j` forces `f(j) ≥ j+1`. Staircase: f nondecreasing with no fixed point above β gives, by the same induction, `f(y) ≥ y+1` for all `y ≥ j` — so `f(N) ≥ N+1`, impossible on the chain. ∎

**Dual.** If `b(τ) ⊒ τ` and τ ≻ 0, then `a(τ−1) ⊒ τ`.

**Corollary (automatic pinning).** In any polar configuration satisfying both band conditions, the derived maps are *pinned*: `b(β+1) ∈ B` and `a(τ−1) ∈ T`. There is no intermediate regime where the bands hold without pinning. Combined with §16.2(3) (commutation forces the bands), any commuting polar configuration on a finite chain must exhibit the full pinned geometry.

### 17.2 Dichotomy of the middle band, and the collapse of adjacent bands

**Lemma (Dichotomy).** In a commuting polar configuration with β ⊏ τ, every `i ∈ M = (β,τ)` satisfies: `a(i) ∈ T ⟹ b(i) ∉ B`. So M splits into the disjoint sets `M_B = {i : b(i) ∈ B}` and `M_T = {i : a(i) ∈ T}`.

*Proof.* If `b(i) ∈ B` and `a(i) ∈ T`, band invariance gives `a(b(i)) ∈ B` and `b(a(i)) ∈ T`; commutation forces `B ∩ T ≠ ∅`, contradicting §16.2(3). ∎

**Case A collapse.** Commutation forces `B ∩ T = ∅`, i.e. β ⊏ τ on a chain; and τ = β+1 dies by the seam lemma (§16.2(4): `β ⊏ F(β,τ) ⊏ τ` with an empty open interval). Hence any commuting polar configuration on a finite chain has a **nonempty middle band**: τ ⊒ β+2, split two ways by the dichotomy, with b pinned below β+1 and a pinned above τ−1.

### 17.4 Near-miss remark: why rounding saves finite chains

On the 3-chain, `F(x,y) = ⌈(x+y)/2⌉` — the rounded [0,1] counterexample of §16.1 — gives `a = [1,2,2]`, `b = id`: the derived maps commute, and the common fixed set is {2}: a *unique* common fixed point, `m = n = 2`. The unrounded trick (`a = b = id`, a continuum of common fixed points) cannot survive on a finite chain — rounding pins the derived maps off the boundary. Any claimed finite counterexample must additionally survive I1 (`m ⊑ n`, proven), the band lemmas (§16.2), the base cases (§16.3), and now the squeeze.
