## 21. Thirteenth Exploration Round (v2.4): The Sharp Boundary — ω+1

The twelfth round left one frontier: does the Finite Commutation Lemma survive its first infinite test, the chain ω+1 (bottom 0, naturals, top ω)? This round answers it completely: **it does not.** The boundary between "commutation lemma holds" and "commutation lemma fails" is exactly the finite/infinite boundary among the chains examined so far — finite chains ✓ (§20.5), ω+1 ✗ (this round), [0,1] ✗ (§16.4). The failure has a precise, checkable mechanism: the dissolution of the top pin.

### 21.1 The Transfer Theorem

Every ingredient of the §20.5 proof transfers to ω+1 verbatim as long as the band parameters β, τ are finite:

1. **Row Staircase (ω+1 version).** If row x's fixed points are all ⊑ c with c finite, then F(x,y) ⊑ y−1 for every finite y > c. *Proof (bounded ascent).* Suppose F(x,y₀) ≥ y₀ for some finite y₀ > c. The orbit y ↦ F(x,y) ascends from y₀; its limit is a fixed point of the row map. If the orbit ever reaches ω, then F(x,ω) is finite (ω itself would be a row fixed point > c, contradicting the hypothesis), and the ascent restarts bounded: the tail orbit ascends inside [0, F(x,ω)], hence stabilizes at a fixed point ≤ F(x,ω) — which, being finite and ≥ y₀ > c, again contradicts the hypothesis. So the orbit is bounded and stabilizes at a finite fixed point > c. Contradiction. ∎ (This is the fixed-point lemma for normal functions: a normal map on ordinals has arbitrarily large fixed points; a monotone row map with no fixed point above c cannot climb past any y > c — cf. the standard normal-function fixed-point lemma, e.g. as in Cantor's theorem on normal functions.)
2. **Column ascent pigeonhole.** Upward induction from 0 works verbatim: a column map on ω+1 with no fixed point below y must strictly increase through every finite level; the ascent to ω either terminates at a finite fixed point or restarts bounded, as above.
3. **Pinning transfers.** Bottom pin: b(β+1) ∈ B follows from F(β, β+1) ⊑ β (row β, no fixed points above β) against band 2's F(β,β+1) ⊒ β+1 — the same two-cell squeeze as §20. Top pin: a(τ−1) ∈ T whenever τ is finite (τ−1 exists).
4. **Seam argument.** τ = β+1 dies exactly as in §20.5: the sink set K ⊆ [β+1, s] is finite, has a maximum s, and the boundary cell F(s, s+1) is crushed between a row bound ⊑ s and a column bound ⊒ s+1.
5. **B ∩ T = ∅** is impossible as before (i ∈ T forces a(i) = ω; band 1 forces a(i) ⊑ β on B).
6. **β = ω ∧ τ < ω** is impossible: band 1 needs a(ω) ⊑ β = ω, fine, but b(T) ⊆ T with T = [τ, ω] and the composite arguments of §20.4 lift to ω+1.
7. **Finite corridor ⟹ max K exists.** If K ⊆ M is finite, it has a maximum; orbits of h on B stabilize at 0 in one step (h ≡ 0 on B) and at ω on T (h ≡ ω on T), so all §20 machinery is available.

**Transfer Theorem.** *On ω+1, every commuting band-satisfying polar configuration with finite β, τ, or with β = τ = ω is impossible except possibly when τ = ω > β; in every case with τ = ω > β (finite or ω), commutation forces the analysis into the infinite corridor — and the constructions of §21.3 show such configurations exist. Consequently: any commuting band-satisfying polar configuration on ω+1 must have τ = ω.* ∎

The proofs use only: monotonicity, the normal-function fixed-point lemma (a monotone self-map of a well-order either has arbitrarily large fixed points or is bounded above — see the standard fixed-point lemma for normal functions), and the absence of an immediate predecessor of ω (in ω+1 the top element ω is a limit: it has no immediate predecessor; cf. the standard theory of well-orders and limit elements).

### 21.2 The ω+1 dichotomy: commutation forces τ = ω

Combining the Transfer Theorem's cases:

- β, τ both finite: the §20.5 seam argument runs verbatim (K finite, max K exists, boundary cell contradiction). Impossible.
- β = ω, τ < ω: impossible (case 6).
- β = ω = τ: the corridor M is empty; this case is realized — see Example (i) below.
- τ = ω > β (β finite or ω): the top pin dissolves (ω has no predecessor, so there is no cell a(τ−1) to anchor), the sink set K = {finite naturals ≥ β+1} has **no maximum**, so there is **no boundary cell** and the §20.5 argument has no grip. This case is realized — see Example (ii) below.

So the dichotomy of §16.5 is resolved: **FCL fails on ω+1, and it fails only through τ = ω.**

### 21.3 The two counterexamples (machine-verified)

Both configurations take the trivial-commutation form a = id (then a∘b = b = b∘a). The content is that all structural side-conditions — monotonicity, polarity, bands, pinning — are satisfied while m ≠ n.

**Example (i): β = ω = τ, empty corridor.**

F(x,y) = x for finite x, y; F(x,ω) = x+1 for finite x; F(ω,ω) = ω; F(ω,y) = ω.

- a(x) = x for all x (row x has greatest fixed point x: F(x,x) = x, and F(x,x+1) = x < x+1); a(ω) = ω.
- b(y) = 0 for finite y, b(ω) = ω (column y has least fixed point 0: F(0,y) = 0; column ω has least fixed point ω).
- Bands: B = ∅ = T vacuously; polarity holds (F(0,y) ≤ y, F(x,ω) ≥ x trivially; F(ω,y) = ω, F(x,ω) = x+1 > x).
- φ = ψ = b; **m = 0 ≠ ω = n.** Commutes.

**Example (ii): β = 1, τ = ω, infinite corridor M = {2, 3, …}.**

F(0,y) = 0 for y ≤ 1, 1 for finite y ≥ 2; F(0,ω) = 1; F(1,y) = 1 for finite y, F(1,ω) = 2; F(x,y) = x for finite x ≥ 2, y finite; F(x,ω) = x+1; F(ω,y) = ω.

- a = id on all of ω+1: row 0 has greatest fixed point 0 (F(0,0)=0; F(0,1)=0≠1, and F(0,y)=1<y for finite y≥2); row 1 has greatest fixed point 1 (F(1,1)=1; F(1,y)=1<y for y≥2); every finite row x ≥ 2 has greatest fixed point x (F(x,x)=x, F(x,x+1)=x<x+1); row ω has greatest fixed point ω (F(ω,ω)=ω). Hence a(0)=0 and a(x)=x for all x ≥ 1: a is the identity on the whole chain.
- b = [0, 0, 1, 1, 1, …, ω]: b(0)=0, b(1)=0 (column 1: F(0,1)=0), b(y)=1 for finite y ≥ 2 (column y: F(1,y)=1), b(ω)=ω (column ω: F(ω,ω)=ω... least x with F(x,ω)=ω is x=ω? F(1,ω)=2, F(x,ω)=x+1 for finite x — never ω; so b(ω)=ω).
- Bands: a(↓1) = ↓1 ✓ (a=id); b([ω,ω]) = {ω} ✓. Bottom pin: b(β+1) = b(2) = 1 ∈ B ✓. Top pin: **does not exist** — τ = ω has no predecessor.
- φ = a∘b = b = b∘a = ψ; **m = 0 ≠ ω = n.** Commutes, with an infinite corridor and a surviving bottom pin.

**Machine verification.** Both examples were verified on truncations [0..K] + {W} for K = 10, 25, 60 (both kinds): monotonicity ✓, polarity ✓, bands ✓, a = id on the interior [0..K−1] ✓, b-formula exact ✓, commutation exact on the interior ✓, m = 0 ≠ n = W ✓, every interior corridor index sinks to 0 ✓, bottom pin b(2)=1 ∈ B ✓ (kind 2). The only failures appear at the truncation seam: exactly at index K, a(K)=W (the truncation forces the top into the last row) and the commutation check fails exactly there — i.e., **FCL "bites" precisely at the artificial seam**, exactly as predicted: the finite chain proof kills the truncation, the infinite original escapes through the missing boundary cell.

### 21.4 The mechanism: pinning asymmetry

The two counterexamples isolate exactly which ingredient of the finite proof fails:

- **The bottom pin survives.** In Example (ii), b(β+1) = b(2) = 1 ∈ B. The finite chain's two-cell squeeze F(β,β+1) ⊑ β vs ⊒ β+1 uses only row β and band 2, and both are intact at β = 1. Downward-pinning is a local, two-cell fact and does not need a predecessor.
- **The top pin dissolves.** a(τ−1) ∈ T requires the cell τ−1. At τ = ω there is no such cell: ω is a limit element with no immediate predecessor. Upward-pinning is anchored at a *predecessor* and is the only ingredient that is not local.
- **The sink set loses its maximum.** K = {finite naturals ≥ β+1} has no maximum, so there is no boundary cell (s, s+1) at which the row/column squeeze of §20.5 can fire. The seam argument needs a *last* element of the sink set; the infinite corridor has none.

**Re-reading [0,1] (§16.4).** The v1.9 counterexample is the same mechanism, compressed: in a dense order *every* element lacks immediate predecessors, so *both* pins dissolve, and no element of the corridor is "last" in any direction. ω+1 shows that dissolving one pin (the top) already suffices. The pinning pair {b(β+1) ∈ B, a(τ−1) ∈ T} is therefore the load-bearing wall of the Commutation Lemma, and predecessor-existence is its foundation.

A small completeness remark: on ω+1 every monotone self-map has both a least and a greatest fixed point (if f(ω) = ω, done by restriction to the finite part; otherwise f(ω) is finite and the gfp is found by the bounded-ascent/descent argument of §21.1), so a and b are always well-defined there — the failure is genuinely about commutation, not about fixed-point existence. (This is the classical Knaster–Tarski/complete-lattice situation; the constructive, transfinite-iteration view of these fixed points is the Cousot–Cousot constructive Tarski theorem, which shows the fixed points are reached by ordinal-indexed iteration.)

### 21.5 Consequences: the Sharpness Conjecture

The Commutation Lemma is now exactly characterized on the three regimes examined:

| Chain | CL status | Mechanism |
|---|---|---|
| finite chains | **true** (§20.5) | both pins present, K has a max, boundary cell contradiction |
| ω+1 | **false** (§21.3) | top pin dissolves (ω has no predecessor), K has no max |
| [0,1] | **false** (§16.4) | both pins dissolve (density), no last elements anywhere |

**Sharpness Conjecture.** *A complete chain satisfies the Commutation Lemma if and only if it is finite.*

The necessity direction is proved; the sufficiency direction (every infinite complete chain admits a commuting band-satisfying polar configuration with m ≠ n) is the open part. The suggested engine: every infinite complete chain has an element with no immediate predecessor (else, starting from the bottom, every element is reached by finitely many successor steps, making the chain finite). Pick such a limit element λ; the ω-sequence cofinal below λ plays the role of the naturals below ω, and the a = id construction of §21.3 (Example i pattern transplanted below λ, with everything at-or-above λ mapped identically to the top's side) should yield a commuting counterexample. Formally: let g: ω → cofinal sequence below λ; define F(g(k), y) = g(k) for y < λ finite-in-sequence, F(g(k), λ-side) = g(k+1), and F(x, ·) = appropriate constants on the complement — the verification reduces to the machine-checked ω+1 case elementwise.

Literature notes (plain references): the fixed-point lemma for normal functions (Cantor; every normal ordinal map has a club of fixed points) underlies §21.1; the no-immediate-predecessor property of limit elements is standard well-order theory (ω is a limit ordinal, no immediate predecessor); the constructive Knaster–Tarski theorem (Cousot–Cousot 1979: least/greatest fixed points by transfinite iteration) is the constructive infinite analogue of the finite orbit arguments; Mathlib's `previous_fixed_point` for monotone maps documents the same least/greatest fixed-point duality.

### 21.6 Open problems (after round thirteen)

1. **Prove the Sharpness Conjecture.** Extend the a = id construction of §21.3 to an arbitrary infinite complete chain: anchor below a limit element λ with a cofinal ω-sequence, transplant Example (i)'s pattern below λ, and collapse the rest. The ω+1 case (machine-verified) is the template; the remaining work is handling chains with several limit strata (e.g. ω² + 1) and with no cofinal ω-sequence below any single element (e.g. ω₁ — where cofinality is the obstruction and the conjecture may need the refinement: a counterexample exists iff some element has countable cofinality).
2. **Beyond chains.** Which complete lattices satisfy the Commutation Lemma? ω+1 shows predecessor-existence is the delicate axiom; [0,1] shows density kills it. Candidate boundary: complete lattices in which every element is a finite successor-of-successor from ⊥ (exactly the finite chains) satisfy CL; conjecturally nothing else does. The O-class (§20.3) and near-miss census (§20.4) suggest that in any failure the corridor must contain a "sink/rise seam" with no boundary cell.
3. **Failure zone** (unchanged, §15.3–15.4): structural characterization of non-iso δ₀ beyond the two degenerating positive classes.
