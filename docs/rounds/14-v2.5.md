## 22. Fourteenth Exploration Round (v2.5): The Sharpness Theorem — the Chain Problem Closed

Round thirteen left the Sharpness Conjecture (§21.5): *a complete chain satisfies the Commutation Lemma iff it is finite*, with the necessity of finiteness proved and the sufficiency (counterexamples on every infinite complete chain) open. This round closes it. Four new ingredients assemble into a proof: a Duality Theorem, a Ladder Lemma, a general Ladder Construction, and a corrected Infinitude Lemma.

### 22.1 The Duality Theorem

Let L be a complete lattice, F : L×L → L monotone in each argument, and h : L → Lᵒᵖ the order-reversing identification of L with its opposite. Define the **dual bifunction** on Lᵒᵖ:

```
Fᵈ(x, y) := h( F( h(y), h(x) ) )      (order reversal + transpose)
```

**Theorem (Duality).** For the derived maps of Fᵈ on Lᵒᵖ: `aᵈ = h ∘ b ∘ h⁻¹`, `bᵈ = h ∘ a ∘ h⁻¹`, hence `φᵈ = h ∘ ψ ∘ h⁻¹` and `ψᵈ = h ∘ φ ∘ h⁻¹`. Consequently: (i) Fᵈ is monotone iff F is; (ii) the derived pair of Fᵈ commutes iff that of F does; (iii) Fᵈ is polar iff F is; (iv) `mᵈ = h(n)` and `nᵈ = h(m)`, so `mᵈ ≠ nᵈ ⟺ m ≠ n`; (v) the bands swap: `Bᵈ = h(T)`, `Tᵈ = h(B)`, and boundary repulsion at one side becomes repulsion at the other. **The Commutation Lemma holds on L iff it holds on Lᵒᵖ.**

*Proof.* Fixed points of row x of Fᵈ are exactly h(fixed points of column h(x) of F): Fᵈ(x,y) = y ⟺ h(F(h(y),h(x))) = y ⟺ F(h(y),h(x)) = h(y). Greatest in Lᵒᵖ is least in L, giving aᵈ = h∘b∘h⁻¹; the rest follows by composing. Bands: Bᵈ = (bᵈ)⁻¹(⊥ᵒᵖ) = h(a⁻¹(⊤)) = h(T). ∎

**Machine validation (exhaustive).** All 24,696 monotone bifunctions on chain-4 (regenerated independently; the count and the 12,450 commuting cases match the v1.8 census of §15.1 exactly, and the zero polar-violator count reconfirms FCL): for every F and its dual G[x][y] = (n−1) − F[n−1−y][n−1−x], the identities a_G[x] = n−1−b[n−1−x], b_G[x] = n−1−a[n−1−x], commutation-transfer, m_G = n−1−n_F, n_G = n−1−m_F, polarity-transfer, and monotonicity of G: **zero failures in 24,696/24,696 cases.** (A first implementation omitting the outer reversal h failed 12,556 commutation transfers — the transpose alone is *not* the dual; the reflection of the output is essential.)

**Corollary (co-limit route).** If Cᵒᵖ carries a commuting polar configuration, so does C. Since (ω+1)ᵒᵖ ≅ 1+ω*+1, the §21 counterexamples transpose to 1+ω*+1 — a chain in which *every element has an immediate predecessor*. This refutes any "predecessor criterion": the correct symmetric notion is *limit element (no immediate predecessor) or co-limit element (no immediate successor)*. Machine check: the transposed Example (ii) on a 1+ω*+1 surrogate (K=12) is monotone, polar, with aᵈ = [0,12,12,…,13], bᵈ = id except at the seam image (bᵈ = [0,0,2,3,…,13]), m = ⊥ ≠ ⊤ = n, and commutation exact everywhere except exactly at index 1 = h(K), the image of the truncation seam — the finite Commutation Lemma biting precisely where the surrogate is artificial.

### 22.2 The Ladder (Escape) Lemma

The §21 constructions needed, below a limit element λ, a monotone **escape map** s with x < s(x) < λ. Round thirteen worried this requires countable cofinality (an ω-sequence cofinal below λ). It does not.

**Lemma (Ladder/Escape).** Let λ be an element of a chain with no immediate predecessor. Then there is a monotone s : ↓λ ∖ {λ} → ↓λ ∖ {λ} with x < s(x) < λ for all x < λ.

*Proof.* Every linear order admits a well-ordered cofinal subset (the cofinality theorem: the cofinality of a linear order is the least well-order type of a cofinal subset — Hausdorff's notion; "if A admits a totally ordered cofinal subset, then we can find a subset B that is well-ordered and cofinal in A"; the general statement for linearly ordered sets is equivalent to a weak form of choice). Apply this to ↓λ ∖ {λ}: get W well-ordered and cofinal below λ. Define s(x) := min{w ∈ W : w > x}. The set is nonempty for every x < λ: W is cofinal, and W has no greatest element (a greatest rung w would give sup W = w < λ, contradicting cofinality). Monotonicity: x ≤ x′ implies {w > x′} ⊆ {w > x}, so min{w > x} ≤ min{w > x′}. Strictness is by construction, and s(x) ∈ W ⊆ ↓λ ∖ {λ}. ∎

No arithmetic is used — no midpoints, no countability. On ordinal-type limits W can be the ordinal itself and s(x) = x+1 (the §21 engine); on [0,1) one may take W = {1 − 2⁻ⁱ}; on 1+ω*+ω+1 the ladder **jumps the ω*-segment entirely** (W = the top ω-part; s sends every element of the ω*-part to the first rung) — defeating the "inf-crush" obstruction that naively forbids segment-wise ascent below a limit sitting above a reverse-ω segment.

### 22.3 The Ladder Construction

Let C be a complete chain, λ a limit element with λ > ⊥, and s a ladder below λ. Define:

```
F(x, y) = x          if y < λ           (all x)
F(x, y) = s(x)       if y ≥ λ and x < λ
F(x, y) = max(x, y)  if x ≥ λ and y ≥ λ
```

**Theorem.** F is monotone in each argument, and its derived pair is a commuting polar configuration with m = ⊥ ≠ ⊤ = n.

*Proof.* Monotonicity: the three regions paste along the seams x ≤ s(x) and max(x,y) ≥ x. Rows: for x < λ the only fixed point of y ↦ F(x,y) is y = x (the y ≥ λ columns carry s(x) < λ ≤ y), so a(x) = x; for x ≥ λ the fixed points are [x, ⊤] (region max), so a(x) = ⊤. Columns: for y < λ every row is a fixed point, so b(y) = ⊥; for y ≥ λ the fixed points are {x ≥ y}, so b(y) = y. Hence a = id ∨ [λ,⊤]-const-⊤, b = ⊥-below-λ ∨ id-on-[λ,⊤]; φ = a∘b = ψ = b∘a is the step map (⊥ below λ, ⊤ from λ on) — commutation is exact, not asymptotic. Polarity: a(⊥) = ⊥, a(⊤) = ⊤, b(⊥) = ⊥, b(⊤) = ⊤. Fixed points: Fix(a) = ↓λ∖{λ} ∪ {⊤}, so m = μ(a) = ⊥; Fix(b) = {⊥} ∪ [λ,⊤], so n = ν(b) = ⊤; m ≠ n since λ > ⊥. Bands: B = {y : F(⊥,y) = ⊥} = {y < λ} — a down-set with **no maximum** (λ is a limit); T = {x : F(x,⊤) = ⊤} = [λ,⊤]; B ∩ T = ∅ and B ∪ T = C: the V2 shape with an *empty corridor and no boundary cell* — the §21.4 mechanism (dissolved pin, sink set without max) now in its general form. ∎

**Regimes covered and machine-verified** (finite surrogates of the infinite chains; checks: monotone, polar, m ≠ n, and commutation exact except at the predicted truncation seam):

| Chain | λ position | Ladder W | Surrogate result |
|---|---|---|---|
| ω+1 | top | all naturals (= §21 Ex (i)) | interior exact, seam at K |
| 1+ω*+ω+1 | top | top ω-part (**jumping** ladder) | interior exact, seam at last rung |
| 1+ω+1+ω*+1 | **interior** | ω-part below λ | interior exact, seam at K+1 |
| ω+2 | interior, top has predecessor | finite part | interior exact, seam at K |
| [0,1] | top | {1 − 2⁻ⁱ} | interior exact, seam at last rung |
| 1+ω*+1 | no limit — **duality route** | transpose of Ex (ii) | interior exact, seam at h(K) |

Every finite surrogate *must* fail somewhere (FCL, §20.5); the machine confirms it fails **exactly at the clamp/seam and nowhere else** — the infinite chain's commutation is verified in the limit by the proofs above, and the surrogate failures localize precisely the artificial truncation. The [0,1] row also yields a second, purely order-theoretic [0,1] counterexample (F(x,y) = x off the top column, next-rung on it) beside the v1.9 arithmetic one — same failure, no midpoint arithmetic, just cofinality.

### 22.4 The Infinitude Lemma (corrected)

The §21.5 rationale — "every infinite complete chain has an element with no immediate predecessor, else it is a finite successor chain from the bottom" — is **false**: 1+ω*+1 is infinite, complete, and every element has an immediate predecessor (the bottom has no *successor*, which the old argument never examined). The corrected statement:

**Lemma (Infinitude).** Every infinite complete chain has an element λ > ⊥ with no immediate predecessor, or an element κ < ⊤ with no immediate successor.

*Proof.* Suppose not: every element > ⊥ has an immediate predecessor p(x) and every element < ⊤ an immediate successor s(x). The orbit ⊥ → s(⊥) → s²(⊥) → ⋯ strictly ascends. If it never reaches ⊤, let λ = sup (exists by completeness). If λ < ⊤: p(λ) < λ means p(λ) is not an upper bound of the orbit, so some o ∈ O satisfies o > p(λ); as o ≤ λ and (p(λ), λ] = {λ}, we get λ ∈ O, whence s(λ) ∈ O exceeds sup O — contradiction. If λ = ⊤: ⊤ has an immediate predecessor p, and the same argument puts ⊤ ∈ O, contradicting "never reaches ⊤". So the orbit reaches ⊤ = sᴺ(⊥); but each step is an *immediate* successor, so the open intervals between consecutive orbit elements are empty, and C = {⊥, s(⊥), …, ⊤} is finite — contradiction. ∎

### 22.5 The Sharpness Theorem

**Theorem (Sharpness, v2.5).** A complete chain satisfies the Commutation Lemma **if and only if it is finite**.

*Proof.* (⟸) The Finite Commutation Lemma, §20.5. (⟹) Let C be an infinite complete chain. By the Infinitude Lemma, C has a limit λ > ⊥ or a co-limit κ < ⊤. Co-limit case: in Cᵒᵖ the element h(κ) has no immediate predecessor and is not the bottom, so Cᵒᵖ falls into the limit case, and the Duality Theorem transports any counterexample back to C. Limit case: the Ladder Lemma supplies a monotone escape s below λ, and the Ladder Construction yields a commuting polar configuration with m = ⊥ ≠ ⊤ = n. Either way C carries a commuting polar configuration, so the Commutation Lemma fails on C. ∎

**The chain problem of the Commutation Lemma is closed:** the boundary is exactly the finite/infinite line, first observed as a three-point pattern (finite ✓ / ω+1 ✗ / [0,1] ✗, §21.5), now a theorem.

**Consequences.**

1. **The interpolation-room conjecture (§16.5) is resolved negatively.** The Ladder Construction on ω+1 has F(⊥,⊤) = s(⊥) = the first rung 1, and the lower room (⊥, 1) is *empty* (ω+1 has no element between 0 and 1). Interpolation room is not necessary for failure; the No-Room Lemma (§16.2) needs *both* rooms empty, and the sharp boundary is finiteness itself, not room.
2. **The pinning analysis of §21.4 is confirmed in general.** In every Ladder counterexample the band B = {y < λ} has no maximum (λ is a limit) — there is no boundary cell and no top pin; the Duality route fails instead through the mirror image (no bottom pin). A commuting polar configuration exists precisely when one of the two pins cannot be anchored.
3. **Cofinality is irrelevant.** The ω₁+1 case of §21.6(1) is settled by the same construction: s(x) = x+1 below ω₁ (every ordinal has a successor below a limit), so CL fails on λ+1 for **every** limit ordinal λ, of any cofinality.
4. **The failure propagates.** If a complete lattice L contains a failing chain as an interval [z, z′] (e.g. [0,1], or any ω+1-interval), the polar configuration transports along the interval isomorphism, so L fails too; products of failing chains fail coordinatewise. Hence infinite complete lattices satisfying CL must exclude all failing chains as intervals — the height-3 diamonds M_κ (any κ, §16.2) do, and are the standing examples of infinite complete lattices on which CL holds. Sharpness therefore does **not** extend verbatim to lattices: the finite/infinite line is a chain phenomenon.

Literature notes (plain references): the cofinality theorem for linear orders (Hausdorff: cofinality as the least well-order type of a cofinal subset; every linearly ordered set has a well-ordered cofinal subset, a statement equivalent over ZF to a weak form of the axiom of choice) underlies the Ladder Lemma; order-theoretic duality (reversal of the order, the h-map of §22.1) is the classical duality of lattice theory; the fixed-point backdrop remains Knaster–Tarski and its constructive transfinite-iteration form (Cousot–Cousot), as cited in §21.

### 22.6 Open problems (after round fourteen)

1. **The lattice frontier.** Characterize the complete lattices on which the Commutation Lemma holds. Chains are closed (finite ⟺ CL). For general complete lattices the standing positive class is height ≤ 3 (No-Room, §16.2 — including the infinite diamonds M_κ) and the standing negative class is "contains a failing chain as an interval" (transport along the interval, §22.5.4). The open question: is every failure on a complete lattice *already* witnessed by a failing chain interval — i.e., CL holds on L iff no interval of L is order-isomorphic to a carrying chain of a polar configuration? A negative answer would exhibit an essentially two-dimensional failure. **Resolution (v2.6, §23):** the answer is **negative**. The powerset 2^ω carries a commuting polar configuration witnessed by the subchain-retract of initial segments ≅ ω+1 — an essentially two-dimensional failure (§23.3) — and Theorem A (§23.2) shows that *every* complete lattice containing an infinite chain fails CL. The frontier is now exactly the chain-finite complete lattices (§23.4–23.5).
2. **Failure zone** (unchanged, §15.3–15.4): structural characterization of non-iso δ₀ beyond the two degenerating positive classes.
