## 24. Sixteenth Exploration Round (v2.7): The Pair-Level Method — Realizability and the Machine Proof at Height 4

Round fifteen left the chain-finite frontier with censuses that were confirmatory but not probative (§23.4–23.5). This round changes the unit of attack: instead of searching the space of monotone bifunctions F (astronomically large and impossible to enumerate beyond the smallest lattices), it searches the space of *pairs* of monotone self-maps — a finite, completely enumerable space — and decides realizability by an exact constraint system. The payoff is the first complete proof in the frontier beyond chains and No-Room: **CL holds on E₂**, the column lattice of height 4, the first open lattice of the frontier.

### 24.1 The Pair-Level Reduction and the Realizability Criterion

*Correction (round 26, §34.3e): read "on some interval [z, z′] of L" for "on L"; a violator is polar only on [m, n]. Checked in `lean/Mordor/Restrict.lean`.*

**Theorem (Pair-Level Reduction; formalizing §15.1).** CL fails on a complete lattice L iff there exists a *commuting polar pair* (a, b) — monotone self-maps with a(⊥) = b(⊥) = ⊥, a(⊤) = b(⊤) = ⊤, a∘b = b∘a — that is **realizable**: a = a_F and b = b_F for some monotone bifunction F : L×L → L.

*Proof.* For a polar pair, Fix(a) contains ⊤-witnessing structure forcing m = μ(a∘b) = ⊥ and n = ν(b∘a) = ⊤ (§15.1); so a realizable commuting polar pair is a CL violator, and conversely a violator's derived pair is commuting and polar. ∎

For finite L this converts an unsearchable question (does *any* F violate CL?) into a finite one: enumerate polar pairs, test commutation, decide realizability. Polar pair counts are small — E₂ has 4,356 polar maps (66², one 66-count weak-3-chain of images per column), B3 has 5,832 (18³), E₃ has 912,673 (97³), E₄ has 268,435,456 (128⁴) — against, e.g., 16,818,516 monotone bifunctions already on the 5-chain (§16.4).

**Proposition (Realizability Criterion — the exact CSP).** Let L be finite and (a, b) a pair of monotone self-maps. A monotone F has derived pair (a, b) iff it satisfies:

1. **(Pins)** F(x, a(x)) = a(x) and F(b(y), y) = b(y) for all x, y;
2. **(Greatest-fp exclusion)** y ≰ a(x) ⟹ F(x, y) ≠ y for all cells (x, y);
3. **(Least-fp exclusion)** x ≱ b(y) ⟹ F(x, y) ≠ x for all cells (x, y).

(Note ≰ covers both "below" and "incomparable" — incomparability also forces the exclusion.)

*Proof.* (⟹) If a = a_F, then a(x) is a fixed point of the row map y ↦ F(x, y), giving pin 1; any y with F(x, y) = y is a row fixed point, hence y ≤ a(x), giving exclusion 2 by contraposition; dually for pin 1′ and exclusion 3. (⟸) Given pins and exclusions: each row map is monotone on a finite lattice, so has fixed points; a(x) is one (pin), and every fixed point y′ satisfies y′ ≤ a(x) (exclusion 2 applied at (x, y′), since y′ ≰ a(x) would force F(x, y′) ≠ y′); hence a(x) is the *greatest* row fixed point, i.e., a_F(x) = a(x). Dually b_F = b. Monotonicity is assumed. ∎

**Machine validation of exactness (chain-4, exhaustive ground truth).** The 24,696 monotone bifunctions of chain-4 (§16.4 census) yield exactly **223 distinct derived pairs**; the CSP answers "yes" on exactly those 223 and "no" on all other candidate pairs, and an independent witness checker (re-deriving a_F, b_F from a found F) passes 223/223. On the 50 abstract commuting violators of chain-4 (§22.1) the CSP says "no" on all — consistent with the Finite Commutation Lemma.

### 24.2 The Squeeze filters (F1–F5)

Five exact unrealizability lemmas, each a one-line consequence of the Criterion. Implemented as O(|L|) bitmask pre-tests, they kill the overwhelming majority of pairs before any search.

**F1 (Identity-Squeeze).** If a = id and ⊤ has a lower cover, (a, b) is unrealizable. *Proof.* Let x ⋖ ⊤. Exclusion 2 at (x, ⊤): ⊤ ≰ a(x) = x, so F(x, ⊤) ≠ ⊤. Monotonicity and pins: F(x, x) = x ≤ F(x, ⊤) ≤ F(⊤, ⊤) = ⊤, so F(x, ⊤) ∈ [x, ⊤) = {x}. Thus x is a fixed point of the column map x ↦ F(x, ⊤), so its least fixed point b(⊤) ≤ x < ⊤ — contradicting b(⊤) = ⊤. ∎

**F2 (dual).** If b = id and ⊥ has an upper cover, unrealizable. ∎ (Mirror of F1.)

**F3 (Local Squeeze — No-Room localized).** If some cover x ⋖ y has a(x) = x and b(y) = y, unrealizable. *Proof.* Pins: F(x, x) = x and F(y, y) = y. Monotonicity on the cell (x, y): x ≤ F(x, y) ≤ y. Exclusions: y ≰ a(x) = x forces F(x, y) ≠ y; x ≱ b(y) = y forces F(x, y) ≠ x. So x < F(x, y) < y with (x, y) = ∅ — impossible. ∎

**F4′ (Cross-Fix, upper).** If a(x) = x then b(x) ≤ x. *Proof.* Pin: F(x, x) = x. If x ≱ b(x), exclusion 3 at (x, x) gives F(x, x) ≠ x. ∎

**F5 (Cross-Fix, lower).** If b(y) = y then y ≤ a(y). *Proof.* Pin: F(y, y) = y. If y ≰ a(y), exclusion 2 at (y, y) gives F(y, y) ≠ y. ∎

Remarks. F1 explains both escapes of §21/§23.3: ω+1 has no lower cover of ⊤ (so a = id survives *there*), while 2^X has coatoms (so a = id is forbidden on powersets). On E₂, F3 kills wholesale — any a fixing a coatom cᵢ dies at the cover cᵢ ⋖ ⊤ since b(⊤) = ⊤ always. F4′/F5 are new this round and close the residual gap between F1/F2/F3 and the CSP on several lattices (§24.4).

### 24.3 Symmetry orbits and the strong solver

**Orbit dedupe.** E₂ carries the column-swap automorphism τ and the anti-automorphism δ; the group ⟨σ₁, σ₂⟩ ≅ V₄ acts on pairs by σ₁(a, b) = (τaτ, τbτ) and σ₂(a, b) = (δbδ, δaδ). Realizability and commutation are invariant under the action, so only the lexicographically minimal representative of each orbit is solved. Completeness: every orbit has a lexicographic minimum; the scan covers all a-index chunks, and each non-minimal pair is skipped exactly when its minimum lies in the scanned range — exhaustive chunk coverage ⇒ every orbit processed exactly once.

**The strong solver.** The CSP is encoded with one bitmask domain per cell (64 cells in E₂): unary constraints from pins and exclusions, binary monotonicity constraints along the 128 cover-edges of the 8×8 product grid; AC-3 arc-consistency propagation, then MRV depth-first search with forward checking for any survivor of propagation. Controls: 77 distinct derived pairs of sampled monotone F — the solver finds explicit witnesses for all (max 42 search nodes), each confirmed by the independent witness checker; the twisted-meet bifunction F(x, y) = σ(x ∧ σ(y)) realizes the pair (σ, const-0), verified by hand and machine. Negative control: the **σ-diagonal pair** — (σ, σ), the column-swap involution with itself, the most natural commuting polar candidate on E₂, with m = ⊥ ≠ ⊤ = n — is refuted in pure propagation. The solver is not blind to the hard cases.

### 24.5 Theorem B: CL holds on E₂

**The E₂ pair scan.** All 4,356² = 18,974,736 polar pairs, scanned in six a-index chunks with early-break commutation tests and bitmask filters; canonical survivors go to the strong solver. Census:

The 4,356 F1-kills form precisely the a = id block (every pair (id, b)); F3 dominates (70.6% of commuting pairs), confirming that cover-fixing pairs are the central obstruction. **Theorem B (E₂).** *The Commutation Lemma holds on the column lattice E₂.*

*Proof.* By the Pair-Level Reduction, CL fails on E₂ iff some commuting polar pair is realizable. The scan enumerates all 18,974,736 polar pairs; every commuting pair is either killed by an exact filter (F1–F5, each a proven lemma, §24.2) or solved by the exact realizability CSP (validated on the 24,696-function chain-4 ground truth and the §24.4 battery); zero are realizable. ∎

Status: the first CL-positive result at height 4 beyond chains, and the first machine proof in the chain-finite frontier. Honest scope: the proof rests on (i) exactness of the CSP (223/223 on exhaustive ground truth), (ii) correctness of the five filter lemmas (hand-proven), (iii) completeness of the orbit dedupe (lexicographic minima + full chunk coverage), and (iv) soundness of the solver's refutations (propagation to empty domain, no search on any E₂ survivor).

### 24.6 The comparability gap (why chains were easy)

An instructive failure, recorded as an insight. A hand proof of E_κ for general κ ≥ 2 was attempted via a cross-column argument (atoms in the B-band, coatoms in the T-band, examination of the cross cell (aⱼ, cᵢ)). It breaks exactly where chain arguments use totality: on a chain, band repulsion gives F(x, y) < y; on a lattice it gives only F(x, y) ≱ y, and incomparability leaks through the argument. This **comparability gap** is the structural explanation of why finite-CL is hard beyond chains: the §20.5 chain proofs are load-bearing on totality, and the two-dimensional case genuinely needs the pair-level machinery (or new theory). Theorem B is therefore not an instance of a known general argument — it is evidence that the frontier holds for reasons the chain theory cannot supply.

### 24.7 Open problems (after round sixteen)

1. **E_κ for κ ≥ 3.** E₃ has 97³ = 912,673 polar maps (≈ 8.3·10¹¹ pairs — beyond complete pair scans); E₄ has 128⁴ ≈ 2.7·10⁸ polar maps. Full enumeration is infeasible; the question needs a lifting theorem (does E₂-CL imply E_κ-CL for all finite κ?) or a smarter invariant. The comparability gap (§24.6) says the natural cross-column route is blocked. **Advances (v2.8, §25):** the block-diagonal family on E₃ — all 592,704 commuting pairs — is completely scanned and clean, so any E₃ violator must be cross-column (§25.4); the naive lifting route is blocked by the Pullback Gap (§25.5); and the merge retractions order the whole family: failure propagates upward (E_j fails ⟹ E_κ fails for j ≤ κ, E_ω included), so E₂ was the forced first target and E₃ is the genuine frontier (§25.5).
2. **B4 = 2⁴.** Infeasible by pair scan (same sizing). The §23.3 corollary shows the retraction-transport family provably contains no B4 violator; a violator, if any, is invisible to retraction from subchains. Chunked or filtered searches (F1 kills a = id wholesale on coatoms, F2 dually) may yet make a partial scan meaningful.
3. **E_ω and infinite chain-finite lattices** (§23.5(1b)): the minimal infinite open class; by Theorem A every infinite CL-positive lattice is chain-finite.
4. **The chain-finite conjecture (strengthened).** Every chain-finite complete lattice satisfies CL. Positive classes now: finite chains (FCL, §20.5), height ≤ 3 (No-Room, §16.2), and E₂ (Theorem B). Note chain-finiteness is equivalent to the conjunction of the ascending and descending chain conditions (ACC ∧ DCC), and neither condition alone suffices — every infinite poset contains an infinite chain or an infinite antichain (a Ramsey-style dichotomy), so width bounds alone cannot stand in.
5. **Failure zone** (unchanged, §15.3–15.4): structural characterization of non-iso δ₀ beyond the two degenerating positive classes.

Literature notes (plain references): the ascending and descending chain conditions for posets and their equivalence with the absence of infinite (ascending/descending) chains are classical order theory (ACC/DCC, Noetherian/Artinian conditions), covered in standard references such as J. Nation's lattice theory lecture notes; the dichotomy that every infinite poset contains an infinite chain or an infinite antichain is a Ramsey-style theorem for ordered sets (under dependent choice, consistent with the DC usage of §23.2); the constraint-propagation methodology (arc consistency, AC-3) is classical constraint satisfaction; the fixed-point backdrop remains Knaster–Tarski and Cousot–Cousot as in §§20–21.
