## 26. Eighteenth Exploration Round (v2.9): The One Crossing — the E₃ One-Crossing Census, the Pentagon Restored, and the Unary Conflict

Round seventeen left E₃ as the frontier: block-diagonal pairs clean (§25.4), the violator (if any) cross-column, no transport route in either direction (§25.5). This round censuses the first complete cut of the cross-column space: **every commuting polar pair on E₃ whose routings cross at most one source column. None is realizable** (§26.4). Combined with §25.4, any E₃ violator must cross at least two source columns — the one crossing is closed. En route: the solver stack revalidated from scratch, with a cover-arc bug found and fixed (§26.1); the v2.8 pentagon "correction" withdrawn — an erratum of an erratum (§26.2); the unary-conflict filter reconstructed and the file closed on the lost F7 (§26.3).

### 26.1 Solver revalidation: exactness, controls, and the cover-arc bug

The realizability machinery was rebuilt from the raw lattices — covers and comparability by transitive closure — and validated bottom up.

**Chain-4 exactness, exhaustively.** All 24,696 fully-monotone bifunctions on the 4-chain were enumerated (an intermediate count of "5,733 derived pairs" was an artifact of enumerating row-monotone-only matrices; monotonicity must hold in both coordinates, and the corrected total is the MacMahon count of §16). The derived pairs collapse to exactly **223 distinct pairs**, and the realizability CSP — monotone F with pins F(x, a(x)) = a(x) and F(b(y), y) = b(y), under the strong Ascent/Descent exclusions — run over all 1,225 monotone map pairs returns exactly **223 satisfiable: set equality** with the derived-pair ground truth (maximum 10 search nodes).

**Polar counts reproduce** from the raw lattices: chain-4: 10; chain-5: 35; M3: 125; N5: 65; E₂: 4,356; E₃: 97 per column (3·35 − 3·4 + 4, the bound-only overcount), 97³ = 912,673 in total. The per-column layer reproduces: M₅ = 35, composition closed, the identity commutes with all 35, in-column commuting pairs P₅ = 351, bound-only maps H4 = {000, 004, 044, 444} (indices 0, 4, 14, 34).

**Controls.** Positive: the twisted meet F(x, y) = σ(x) ∧ y on E₂ derives (σ, const-0) — the solver finds it (sat, 31 nodes, matching §25.1(iv)); greedy-sampled derived pairs are witnessed 10/10 on E₂ (max 42 nodes) and 10/10 on E₃ (max 87 nodes). Negative: the σ-diagonal (σ, σ) refuted at 0 nodes (matching §25.1); the M3 atom-3-cycle collapse pair refuted at 0 nodes.

**The cover-arc bug.** The first rebuild encoded AC-3 monotonicity arcs as grid-index adjacency — cell (i, j) against (i±1, j) and (i, j±1). That is sound only on chains, where index order is cover order; on E₂/E₃ consecutive indices can be incomparable, and the bogus arcs made the solver refute the *realizable* twisted-meet control at 0 nodes. Fix: arcs taken from the lattice cover lists (above/below neighbors), on the full 11×11 grid for E₃ and on chain-5 covers inside block subgrids, with every neighbor of a revised cell re-enqueued. After the fix, all controls pass. Recorded as method, beside §25.1(iv): *a solver that fails a positive control is wrong, however plausible its negative answers* — and index-adjacency propagation is a chain-only shortcut.

### 26.2 The erratum of the erratum: the pentagon restored

What survives unchanged is the battery's conclusion (the pentagon is a zero-realizable control row) and the standing lesson, now doubled: audits are themselves censuses, subject to the same slips; only enumeration from the raw order is self-certifying.

### 26.4 The E₃ one-crossing census and the One-Crossing Theorem

**Block structure.** Comparability across the columns of E₃ runs only through ⊥ and ⊤, so every polar map on E₃ is a **block map**: a routing r: {0, 1, 2} → {0, 1, 2} (target column per source column) plus, per source column, a map from M₅ (the four bound-only maps H4 make that column's routing vacuous). A source column is **crossed** by a map when its routing entry is non-diagonal; a pair is **one-crossing** when at most one source column is crossed, by either map. Up to the S₃ column automorphisms and the pair swap there are four classes: **(id, id)**; **(id, ρ)**, ρ = (0→2, 1→1, 2→2); **(ρ, ρ)**; and the **mixed class (ρ₁, ρ)**, ρ₁ = (0→1, 1→1, 2→2), where the two maps route the crossed column to different targets.

**Commutation decomposes per source column** (composition over M₅; in-column commuting pairs are the 351 of §25.3): for (id, ρ) the crossed column contributes comp[a₂][b₀] = comp[b₀][a₀]; for (ρ, ρ), comp[a₂][b₀] = comp[b₂][a₀]; for the mixed class, comp[a₂][b₀] = comp[b₁][a₀] *with common value in H4* — the two sides land in different target columns, so they can agree only on bounds. Class totals, machine-summed in closed form (20,125,287 = 351 × 57,337), with the conjugate and swap classes reproducing the representatives exactly by independent sums:

| class | commuting pairs |
|---|---|
| (id, id) | 43,243,551 (= 351³) |
| (id, ρ) — conjugates (id, ρ₁), swap (ρ, id) | 20,125,287 |
| (ρ, ρ) | 10,262,889 |
| mixed (ρ₁, ρ) — swap (ρ, ρ₁) | 6,630,376 |

**Block kill tables.** For each source-block (i, j) and per-column pair (u, v) ∈ M₅², the block's 5×5 cell grid is tested with two sound relaxations of the realizability CSP: **T1, unary conflict** — some cell's pin-and-exclusion domain is empty (bound cells never trigger it on E₃; only the 9 interior blocks matter); **T3, block arc consistency** — AC-3 over the block's own cover arcs empties a domain. A pair killed in any block is unrealizable. The tables depend only on the block's routing pattern and are shared across the census, which enumerates commuting tuples per class with early-exit block checks.

The survivor sets coincide exactly with the prior analytic pool → block-filter survivors (e.g. (id, ρ): the analytic pipeline F1–F45 leaves a pool of 546,756, which the block tables cut to 436), so the analytic filters are strictly subsumed: F1/F2/F6/F6′/F8/G5/G6 are unary conflicts (T1); F3/F4′/F5 fall inside block arc consistency (T3). In every class the survivor bins are carried by bound-only column maps (indices in H4 = {0, 4, 14, 34}); the (id, id) census re-derives §25.4's block-diagonal clean from the full 351³ commuting space, and its 64 survivors die at zero nodes here too.

**Theorem (E₃ One-Crossing).** *No one-crossing commuting polar pair on E₃ is realizable.*

*Proof sketch.* Any one-crossing pair admits, after filling vacuous (bound-only) routings diagonally, a routing representation with at most one crossed source column; up to the S₃ column automorphisms and the pair swap it lies in one of the four censused classes. In each class every commuting pair is either killed by a sound relaxation (T1 or T3, conditions every realizable pair survives) or reaches the exact realizability CSP, which returns unsat (exactness: chain-4 exhaustive 223 = 223, §26.1). Conjugate classes transfer because the entire pipeline — domains, arcs, block tables, solver — is equivariant under lattice automorphisms; the swapped class (ρ, id) is not re-censused but transfers at the realizability level, because F′(x, y) = F(y, x) bijects realizations of (a, b) with realizations of (b, a) while preserving commutation and polarity (its commutation total reproduces by machine: 20,125,287). ∎

**Corollary (second structural restriction).** Any CL violator on E₃ must be **multi-crossing**: its derived maps must cross at least two source columns. With §25.4 (block-diagonal clean), the frontier is localized twice over: a violator must leave its columns *and* split its routing across at least two of them.

### 26.5 Honest scope

The theorem covers exactly the one-crossing classes. Multi-crossing pairs (≥ 2 crossed source columns) are unscanned; the full polar space on E₃ is 912,673² ≈ 8.3 × 10¹¹ pairs, and everything above one crossing is the remainder. Class totals are counts in routing representation — pairs with bound-only crossed columns appear in several classes (harmless for refutation; each occurrence is killed or refuted). All refutations are exact — sound exclusions only, no filter can destroy a realizable pair — and the same solver finds every positive control (§26.1).
