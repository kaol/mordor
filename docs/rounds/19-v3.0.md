### 27.1 The two-crossing classes

### 27.2 Interface certificates and the sampling census

The round's first discovery was negative: **the round-18 block tables are too weak here.** For the double-constant class the nine block tables leave 123–1,225 live per-block entries, and block-diagonal blocks kill nothing; the kill in sampled pairs comes from *cross-block* propagation, and every cross-block arc of E₃ passes through a bound cell (comparability across columns runs only through ⊥ and ⊤). Two sound relaxation families were found, both sub-CSPs of the exact realizability CSP (fewer cells, fewer arcs — so sub-unsat ⟹ unrealizable):

- **x-strip_j** (55 cells): all 11 x-values × the column-j chain {⊥, 3j+1, 3j+2, 3j+3, ⊤};
- **interface (i, i′, j)** (40 cells): x ∈ S_i ∪ S_i′ (two columns plus bounds), y ∈ S_j — the smallest certificates that carry cross-block propagation through the bound rows.

**Sampling census.** 1,730 uniformly rejection-sampled commuting pairs across all 21 classes (≈25 per class): every one refuted; zero alive after full-grid propagation. Kill attribution: 1,219 (70.5%) die in full-grid unary conflict (T1); of the remaining 511 propagation-dead pairs, **510 are killed by a single 40-cell interface** and one by a y-strip. Interface kill power is structured: the {0,1}-interface carries nearly all kills in the STAR classes, the {0,2}-interface is needed in the SGL/CHN families, and the {1,2}-interface contributes independently in the TR and ID classes.

**Control honesty.** The round's first control run *failed* — and the failure was in the control, not the solver: the const-0 map had been built through the block-map builder, which forces ⊤ ↦ ⊤, yielding a different (bound-fixing, and unrealizable) pair. With the true twisted-meet witness of §26.1 (b = const-0 with ⊤ ↦ 0, non-polar) the solver returns sat and **every strip and interface sub-CSP is alive** — the certificate families do not over-kill. The lesson of §26.1 is repeated and sharpened: a solver that fails a positive control is wrong, and a control built by the wrong constructor is not a control.

### 27.3 Two full censuses

**Census machinery.** (i) Nine T1 block tables (raw keys (i, j, u, v) ∈ 3·3·35², each a 5×5 unary scan). (ii) Interface tables IF(i, i′, j): for each raw key (A[i], A[i′], v) ∈ 35³ — two a-columns and one b-column — one 40-cell AC-3; for the double-constant class the automorphism π = (1 2) fixes column 0 pointwise and conjugates the class to itself, giving orbit identities IF(0,1,j) = IF(0,2,πj) — machine-verified on 120 random entries (120/120, and table-vs-direct 120/120) — so three tables cover six interfaces. (iii) Structure-aware masked commutation enumeration (star sums for 000.000, transposition 2-cycle sums for 021.021 — both cross-validated against the independent comm totals of §27.1). (iv) Exact solvePair (node cap 300) on every survivor.

Every one of the 65,855 survivors dies **in pure propagation**: full-grid AC-3 from the strong exclusions, zero search nodes, zero caps. The 42,104 total reproduces exactly across two independent A-range passes (24,009 + 18,095); the 021.021 census splits 11,875 + 5,938 + 5,938 over three slices, with a [0,3) diagnostic slice (5,937) consistent. The 021.021 census closes the class containing the σ-diagonal (σ, σ) — refuted in unary since §26.1 — across its entire commuting space.

**Theorem (E₃ two-crossing, first two classes).** *No commuting polar pair on E₃ whose routings are both constant (class 000.000), or both the same transposition (class 021.021), is realizable.*

*Proof sketch.* Each commuting pair in these routing representations is enumerated exactly (masked structure sums validated against independent comm totals); any pair killed by T1 (an empty unary cell) or by an interface sub-CSP (a sub-problem of the exact realizability CSP) is unrealizable; every remaining pair was solved exactly — unsat, in pure propagation, by the solver whose exactness is the chain-4 exhaustive 223 = 223 (§26.1). ∎

### 27.4 Honest scope

Two of the 21 canonical two-crossing classes are fully censused; the other 19 are **sampled but not yet exhaustively refuted** (≈25 pairs each this round, 100% refuted, kill modes recorded). The census machinery is in place for all five commutation structures, with interface families selected per class by measured kill power; the remaining cost is ~2–3 machine slices per class (A-range partitioning keeps each slice inside the process budget; one over-long slice this round timed out and was re-split — the diagnostic-then-slice protocol). No satisfiable witness has appeared anywhere in round nineteen: neither among the 1,730 sampled pairs nor among the 65,855 exactly-refuted census survivors. The representation-counting caveat of §26.5 applies unchanged.
