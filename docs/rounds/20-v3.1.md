## 28. Twentieth Exploration Round (v3.1): The Two-Crossing Census Completed — the Theorem

Round nineteen left 19 of the 21 two-crossing classes sampled but not exhaustively refuted (§27.4). This round closes them all. The machinery was rebuilt and revalidated from scratch (§28.1 — one rebuild bug found and fixed by an internal-consistency tripwire), and the remaining 19 classes were censused and refuted one by one (§28.2): **319,990 fresh exact refutations this round, 456,850 across the two-crossing space, zero satisfiable, zero capped, zero search nodes anywhere** (§27's 65,855 included). The Two-Crossing Theorem follows (§28.3): any E₃ violator must genuinely cross **all three** source columns.

### 28.1 Machinery revalidation; the block-coordinate tripwire

The census stack was rebuilt from the raw lattices and validated bottom up.

**Commutation, all four nest structures exact.** Structure-aware masked enumeration over B given A (per-column composition checks with routing-consistency bits r_k = [r_a[r_b[k]] = r_b[r_a[k]]] and H4 relief where columns disagree) reproduces the round-19 comm totals exactly for six configurations spanning every structure and h4 pattern: STAR 000.002 (4,717,955), CHN 001.021 (2,654,872), CHN 001.001 (3,056,151), SGL 002.010 (9,361,547), SGL 002.102 (4,578,444 — the RB[0] ≠ 0 path, h4 required at k = 0, 1), and ID 012.021 (10,870,821, by factorized column sums — for r_a = id the three per-column conditions decouple). The identity triple commutes with all of M₅, re-verified.

**The block-coordinate tripwire (rebuild bug, found and fixed).** The first rebuilt T1 block table evaluated each 5×5 block's cells at the *images* of the column maps (using a(e3(i,p)) and b(e3(j,q)) as the cell coordinates) instead of at the true coordinates e3(i,p), e3(j,q). The tell was an internal-consistency violation, not a wrong answer: a pair passing all nine T1 blocks can never die at full-grid unary (the nine blocks cover the 11×11 grid and the cellwise domains agree), yet the first SGL run returned 9,271 propagation kills plus 1,557 *unary* kills. The trace localized the mis-evaluated cell at once; after the fix the class reproduces the round-20 anchor exactly (9,271, zero unary kills). Soundness was never at risk — the interface tables and the full-grid unary/AC-3 stages were correct, so every over-admitted pair was still killed by an exact stage — and the R19/R20 records are unaffected (the bug was in the fresh rebuild, not the audited pipeline). Recorded as a standing invariant of this stack: *T1-over-all-blocks is equivalent to full-grid unary nonemptiness; any census where survivors die at the unary stage is broken somewhere between the block builder and the solver.*

**Pipeline anchors exact.** With the fix, the full stack — T1 blocks, interface tables, masked nest, exact solvePair (cap 300) — reproduces three previously-refuted classes across three structures, survivors and kill modes to the last pair: CHN 001.010 → 3,814; SGL 002.021 → 9,271; STAR 000.021 → 15,478; in each, all survivors die in pure propagation (full-grid AC-3), zero unary-stage, zero DFS.

### 28.3 The Two-Crossing Theorem

**Theorem (E₃ Two-Crossing).** *No two-crossing commuting polar pair on E₃ is realizable.*

*Proof sketch.* A two-crossing pair admits, after filling vacuous (bound-only) columns diagonally (§26.5), a routing representation with exactly two crossed source columns; the canonical enumeration of round nineteen (192 routing pairs → 21 classes under S₃-conjugacy × pair-swap, orbit sizes summing to 192) covers them all. In each class every commuting pair is enumerated exactly by the masked structure-aware nest (validated against independent comm totals, §28.1); any pair killed by T1 (an empty unary cell — sound: a realizable pair has F(x,y) in a nonempty domain at every cell) or by an interface sub-CSP (a sub-problem of the exact realizability CSP — sound: restriction of a solution solves the sub-problem) is unrealizable; every remaining pair was solved by the exact CSP solver (exactness: chain-4 exhaustive 223 = 223, §26.1) and returned unsat, in pure propagation, zero search nodes. Conjugate and swapped classes transfer: the whole pipeline — domains, arcs, block and interface tables, solver — is equivariant under lattice automorphisms (E₃'s automorphism group is S₃ on the columns), and F′(x, y) = F(y, x) bijects realizations of (a, b) with those of (b, a) preserving commutation and polarity; the class enumeration is already canonical under both operations, so the 21 censuses cover all 192 routing pairs. ∎

**Corollary (third structural restriction).** Combining §25.4 (block-diagonal clean), §26.4 (one-crossing clean) and §28.3: *any CL violator on E₃ must cross all three source columns* — its derived maps' routings must jointly move every column, i.e. lie among the three-crossing classes (3-cycles and fixed-point-free routings). The E₃ frontier is now exactly the three-crossing region.
