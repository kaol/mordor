## 34.1 Stability theorems: an erratum (§13.1)

`Mordor/Derived.lean` defines a(x) = νY.F(x, Y) and b(y) = μX.F(X, y) (Mathlib's `OrderHom.gfp`, `OrderHom.lfp`), m = μa and n = νb. On any complete lattice it proves L2 (b(m) = m), L1 (a(n) = n), I1 (m ≤ n), fusion (Fix(a∘b) = Fix(a) ∩ Fix(b)), L3, L4, and the I2 characterization (m = n ⟺ a, b have exactly one common fixed point).

**Erratum to the L2 proof (§13.1, step 5).** The log argues: "b(m) is a pre-fixed point of v_{b(m)}; since the greatest fixed point is the infimum of pre-fixed points (Tarski), a(b(m)) ⊑ b(m)". The Tarski fact quoted belongs to the *least* fixed point. A pre-fixed point of a map bounds nothing about its gfp: for the identity every point is pre-fixed and the gfp is ⊤.

The corrected step uses the first half of the proof. With c = b(m) ≤ m, monotonicity gives a(c) ≤ a(m) = m. Then
```
a(c) = F(c, a(c)) ≤ F(c, m) = c,
```
so c is a-pre-fixed and m = μa ≤ c.

**Gap in the L1 proof (§13.1).** The log says "a(n) ⊑ n ⟺ n is a-pre-fixed ⟺ m ⊑ n ⟺ I1". The middle equivalence is not justified: m ≤ n does not by itself make n a-pre-fixed. The direct proof is the dual of the repaired L2. With c = a(n) ≥ n, b(c) ≥ b(n) = n, so
```
b(c) = F(b(c), c) ≥ F(n, c) = c,
```
so c is b-post-fixed and c ≤ νb = n. I1 then follows from L1 (n is a-fixed, so μa ≤ n), the reverse of the log's order of derivation.

All three statements were always true, and the GPU tripwires `trip_l1`, `trip_l2`, `trip_i1` confirmed them on 3.7·10¹¹ bifunctions. Only the written proofs were defective, and no later result depended on the defective steps.

## 34.2 Cut ⟹ semi-CL, per F, without intervals

`Mordor/Cut.lean` defines the Cut Lemma for a single F in both forms of §30.4:
- **cell form:** every nonempty proper down-set D has x ∈ D, y ∉ D with F(x, y) ≤ x or y ≤ F(x, y);
- **map form:** no nonempty proper down-set is closed under a and under b⁻¹.

It proves the two equivalent, per F (`cutCells_iff_maps`).

**Theorem (`semi_of_cut`).** On any complete lattice, if the Cut Lemma holds for F and b∘a ⊑ a∘b, then m = n.

*Proof.* Let D = {x : bᵏ(x) ≤ m for some k}. Then:
- D is a down-set containing m, and b(y) ∈ D implies y ∈ D;
- a(D) ⊆ D, by induction on k: a(m) = m covers k = 0, and b(a(x)) ≤ a(b(x)) carries the step;
- if n ∈ D, then n = bᵏ(n) ≤ m (b(n) = n), so m = n by I1.

So unless m = n, D is a nonempty proper down-set closed under a and b⁻¹. ∎

This sharpens §30.4 in two ways. §30.4 reduced to the polar interval [m, n] and therefore assumed the Cut Lemma *on every interval of L*. Here the sink set is anchored at m instead of ⊥, which needs neither the polar reduction nor the interval. The hypothesis is the Cut Lemma *for this F on L*. So the open problem is now exactly: **for every monotone F on a finite lattice, the map-form cut fails.** No hypothesis about sublattices or intervals is attached.

**The Cut Lemma on finite chains (`cut_finite_chain`).** With d = max D and e = min Dᶜ, either F(d, e) ≤ d, or F(d, e) > d, in which case F(d, e) ∉ D and so F(d, e) ≥ e. The corollaries are `semi_finite_chain` (§30.3) and `fcl`, the Finite Commutation Lemma (§20.5). §20.5's original eleven-step proof via bands, pinning and the composite orbit is no longer needed for the theorem. The machine-checked route is the Cut Lemma on chains followed by `semi_of_cut`.

## 34.3 Principal cuts on finite lattices (§30.4)

`Mordor/PrincipalCut.lean` proves the Cut Lemma for U = ↑u (u ≠ ⊥) and for D = ↓d (d ≠ ⊤) on every finite lattice.

The log iterates τ(x) = F(x, x ∨ u) from ⊥. The formal proof replaces the iteration with a maximal element x of {x ∈ D : x ≤ τ(x)}, which is nonempty because ⊥ is in it. If τ(x) ∈ D, then τ(x) is in the set too, so maximality forces τ(x) = x, a fixed point in D, and (x, x ∨ u) is a witness with F ≤ x. Otherwise τ(x) ≥ u and τ(x) ≥ x, so τ(x) ≥ x ∨ u, a witness with y ≤ F(x, y). The ↓d case is dual, with σ(y) = F(y ∧ d, y) and a minimal element. Only finiteness is used. ACC/DCC versions follow the same pattern with well-founded maximal and minimal elements.

## 34.3a Reachability and the join gap (§31.1)

`Mordor/Reach.lean` defines R(F) as the intersection of all down-sets that contain ⊥ and are closed under a and b⁻¹. It proves two results:
- **`cutMaps_iff_R`:** the Cut Lemma for F holds iff R(F) = L.
- **`R_univ_of_joinClosed`:** on a complete lattice without infinite ascending or descending chains, a join-closed R(F) is all of L.
- **`cutMaps_iff_joinClosed`:** on the same lattices, the Cut Lemma for F ⟺ R(F) is join-closed.

For the second, ACC gives a join-closed nonempty set a greatest element, so R(F) is a principal ideal, and `cut_principal_down` excludes every principal ideal except L. `PrincipalCut.lean` is stated for ACC (the ↑u case) and DCC (the ↓d case), not only for finite lattices. So round 23's reformulation "the Cut Lemma ⟺ R(F) is join-closed" is a theorem, per F, on every chain-finite complete lattice. That includes the infinite frontier D_ω, E_ω and M_ω × C₂.

## 34.3b The Duality Theorem (§22.1)

`Mordor/Duality.lean` defines Fᵈ(x, y) = h(F(h y, h x)) on αᵒᵈ and proves:

## 34.3c Corner and No-Room (§16.2)

`Mordor/NoRoom.lean` proves two results, neither of which needs the polar reduction (§15.1):
- **`corner`:** m < n implies m < F(m, n) < n. This is the log's Corner Lemma, stated at the cell (m, n) instead of the corner (⊥, ⊤) of a polar configuration.
- **`cl_noRoom`:** on a complete lattice in which every element other than ⊥, ⊤ is both an atom and a coatom, a∘b = b∘a forces m = n.

For the second, c = F(m, n) is a middle element, so m = ⊥ and n = ⊤. Then F(⊥, c) = ⊥ and F(c, ⊤) = ⊤, which gives b(c) = ⊥ and a(c) = ⊤, and commutation at c gives ⊥ = ⊤. The lattice may be infinite (M_κ for every κ). This is the edge-height ≤ 2 statement that §30.2(ii) corrected the "height ≤ 3" status line to.

## 34.3d The infinite side: Sharpness and Theorem A (§22, §23)

No machine had checked any of these before; the log's evidence was finite surrogates with predicted truncation seams.

**Ladder Lemma (§22.2, `escape`).** A nonempty linear order without a maximum has a monotone s with x < s(x) for all x. The log invokes Hausdorff's cofinality theorem. The formal proof is shorter:
- take any well-order r of the type (Mathlib's `WellOrderingRel`, from choice);
- its *records* {a : every b with r b a has b < a} form a cofinal set (`isCofinal_setOf_imp_lt`), on which < and r agree;
- s(x) is the r-least record above x. Monotonicity follows from that agreement.

**Ladder and co-ladder (§22.3, `ladder`, `coladder`).**
- Below a limit λ > ⊥: F(x, y) = x if y < λ; s(x) if x < λ ≤ y; max(x, y) otherwise. It has a = id below λ and ⊤ from λ, b = ⊥ below λ and id from λ, exact commutation, and m = ⊥ ≠ ⊤ = n.
- Above a co-limit κ < ⊤: the mirror F(x, y) = y if κ < x; t(y) if x ≤ κ < y; min(x, y) otherwise. This is Fᵈ of the ladder on the dual chain written out directly, which avoids transporting through αᵒᵈᵒᵈ. §22.5 routes this case through the Duality Theorem instead.

**Infinitude Lemma (§22.4, `infinitude`).** An infinite complete chain has a limit λ > ⊥ or a co-limit κ < ⊤. The formal proof replaces the log's successor orbit with S = {x : [⊥, x] is finite}:
- immediate predecessors force sup S ∈ S;
- immediate successors force sup S = ⊤;
- so the chain is finite.

**Sharpness (§22.5, `sharpness`).** For a complete linear order C: CL holds for every monotone F on C ⟺ C is finite. (⟸) is `fcl` (§34.2). (⟹) combines the Infinitude Lemma with the ladder or co-ladder.

**Retract Theorem, abstract form (§23.1, `retract_fail`).** For complete lattices C, L with monotone ι : C → L and σ : L → C such that σ∘ι = id, the transport F = ι∘F₀∘(σ × σ) has a_F = ι∘a₀∘σ, b_F = ι∘b₀∘σ, m_F = ι(m₀) and n_F = ι(n₀). So commutation and m ≠ n transfer. The log required C to be a complete subchain of L containing ⊥, ⊤, with the least-above retraction. None of that is used: C may be any complete lattice that L retracts onto.

**Theorem A (§23.2, `theoremA`, `chainFinite_of_CL`).** If a complete lattice contains an infinite chain, CL fails on it. Equivalently, a CL lattice is chain-finite.

The proof:
- An infinite chain contains a strictly increasing or decreasing sequence c (Mathlib's `exists_increasing_or_nonincreasing_subseq`, plus injectivity and comparability).
- Take C = ℕ∞ (resp. ℕ∞ᵒᵈ), an infinite complete chain, which fails CL by Sharpness.
- Set ι(e) = ⨆_{n ≤ e} cₙ (resp. ⨅) and σ(x) = sInf {e : x ≤ ι(e)} (resp. sSup {e : ι(e) ≤ x}). Then σ∘ι = id because ι reflects <.
- The Retract Theorem transports the failure to L.

The log instead builds the complete subchain {⊥} ∪ {cₙ} ∪ {⋁cₙ, ⊤} inside L. With the abstract Retract Theorem no subchain of L is needed.

## 34.3e Restriction: realizability, polar reduction, escape (§15.1, §24.1, §30.5)

`Mordor/Derived.lean` adds the **Realizability Criterion** (§24.1) as `a_eq_iff` and `b_eq_iff`: a′ = a_F iff the pins F(x, a′x) = a′x hold and every row fixed point lies below a′x, and dually for b. The log states it for finite L; it holds on every complete lattice.

`Mordor/Restrict.lean` proves an embedding lemma, the dual of the Retract Theorem. If a complete lattice T order-embeds into L and is closed under F, a and b, then the restricted derived maps are a|T and b|T, and m, n restrict whenever they lie in T. Three instances follow:
- **Polar reduction (§15.1, `polar_reduction`):** on [m, n] the restriction of a violator is a commuting polar configuration.
- **Converse (`violator_of_interval`):** a violator on any interval [z, z′] transports to L along the retraction x ↦ (x ∨ z) ∧ z′. So CL fails on L iff some interval carries a commuting polar configuration.

  *Correction to §24.1.* The pair-level reduction is stated there "on L", and its proof claims "a violator's derived pair is commuting and polar". A violator is polar only on its interval [m, n]. The README already gives the correct form, the SAT encodings work per interval, and nothing downstream is affected.
- **Escape Lemma (§30.5, `escape_finite`, `escape_infinite`):** a finite sublattice containing ⊥, ⊤, m, n and closed under F, a, b carries a violator. So if CL holds on all finite lattices, every such closure of a violator is infinite.

## 34.3f New: the Cut Lemma at edge-height ≤ 3

**Theorem (`cut_height3`).** Let L be a complete lattice in which every chain ⊥ < x < y < ⊤ has x an atom and y a coatom, i.e. L has no chain of five elements. Then the Cut Lemma holds for every monotone F and every nonempty proper down-set D. Consequently (`semi_height3`, `cl_height3`) semi-commutation, and so commutation, forces μν = νμ on every such L. **That includes the infinite lattices D_ω and M_ω × C₂, which were open frontier** (§23.5, §30.5, §31.5): the cut theory C₃ and the theory T₃ timed out in z3 and Vampire.

*Proof.* Suppose no cell (x, y) with x ∈ D, y ∉ D is a witness, and put c = F(⊥, ⊤). Then c ≠ ⊥, since (⊥, ⊤) would be a witness with F ≤ ⊥, and c ≠ ⊤.
- **c ∉ D.**
  1. c′ = F(⊥, c) ≤ F(⊥, ⊤) = c. It is not ⊥ and not ≥ c, so ⊥ < c′ < c < ⊤, and edge-height 3 makes c′ an atom and c a coatom.
  2. If c′ ∉ D, then F(⊥, c′) ≤ F(⊥, c) = c′ lies strictly between ⊥ and the atom c′, which is impossible. So c′ ∈ D.
  3. Then e = F(c′, c) ≥ F(⊥, c) = c′ is strictly above c′ and not ≥ c, so e is a coatom with e ≠ c.
  4. F(c′, ⊤) ≥ e ∨ c = ⊤, so (c′, ⊤) is a witness. Contradiction.
- **c ∈ D.**
  1. c″ = F(c, ⊤) ≥ F(⊥, ⊤) = c is strictly above c and below ⊤, so c is an atom and c″ a coatom.
  2. If c″ ∈ D, then F(c″, ⊤) ≥ F(c, ⊤) = c″ would be ⊤, a witness. So c″ ∉ D.
  3. Then f = F(c, c″) ≤ c″ is strictly below c″, nonzero and ≰ c, so f is an atom with f ≠ c.
  4. F(⊥, c″) ≤ f ∧ c = ⊥, so (⊥, c″) is a witness. Contradiction. ∎

The edge-height ≤ 2 case (`cut_noRoom`) is the one-step version: one of the cells (⊥, ⊤), (c, ⊤), (⊥, c) is a witness.

The witnesses lie at Kleene-depth ≤ 3 from (⊥, ⊤). This vindicates §31.5's remark that a refutation of C_H should be seeded with short F-iterates from the bounds rather than depth-bounded closures. The minimal unsatisfiable sets of §31.2 run up to 34 cells, but those are cell sets of a fixed down-set in a CSP. Here the case split picks the next cell adaptively, and three or four cells suffice.

**Status after this theorem.** CL and semi-CL hold on every complete lattice of edge-height ≤ 3. Edge-height 4 is the next section.

## 34.3g New: the Cut Lemma at edge-height ≤ 4, by machine (E_ω included)

The witnesses of §34.3f lie within three F-steps of (⊥, ⊤). That suggested searching for the case analysis by machine rather than by hand. `experiments/sat/cut_ground.py` does model-guided ground refutation of the universal cut theory C_H^≤ in the poset version, so it uses neither joins nor meets:
- **Variables:** a Boolean order matrix on a growing set of F-terms built from ⊥, ⊤; down-set membership; and a rank function r : terms → {0..H}, strictly increasing along <, which encodes "no chain of H + 2 elements".
- **Clauses:** reflexivity, bounds, transitivity (added lazily), monotonicity of F, the down-set property and no-witness, all as ground instances. Every clause is an instance of a valid axiom, so UNSAT over any finite term set is a proof.
- **Term growth:** after each model, new terms F(x, y) are added for model pairs x ∈ D, y ∉ D, shallowest first.

**Results:**

| H | result | terms | max depth | time |
|---|---|---|---|---|
| 2 | UNSAT | 6 | 3 | instant |
| 3 | UNSAT | 35 | 6 | instant |
| 4 | **UNSAT** | 388 | 7 | 58 s, 1.77M clauses |

The H = 2 and H = 3 rows reproduce `cut_noRoom` and `cut_height3`.

**Checks on the H = 4 run:**
- **Ablation:** dropping the no-witness axiom stays SAT, as it must.
- **Second solver:** Glucose also reports UNSAT.
- **Independent certificate:** **drat-trim verifies** the DRAT proof. Its core is 385 original clauses over 64 F-terms (depth ≤ 7), and 15 lemmas in 847 resolution steps.

**Lean.** `experiments/sat/cut_lean.py` turns that core into `lean/Mordor/CutHeight4.lean`:
- every core clause becomes an instance of a lemma of `GroundCut.lean` (one lemma per axiom family, each proved once in Lean);
- the rank is encoded as `chainTo x k` ("a strict chain of k + 1 elements ends at x");
- `bv_decide` refutes the 385 instances by replaying a CaDiCaL LRAT proof;
- `tv4 F` instantiates the abstract terms with the actual nested F-expressions.

The theorems:
- **`Ground.cut_height4`:** in every bounded poset with no chain of six elements, every monotone F and every down-set D ∋ ⊥, ⊤ ∉ D have a witness cell.
- **`Height4.cl_height4`, `semi_height4`:** semi-CL and CL on every complete lattice of edge-height ≤ 4, **including E_ω**.

*Trust:* besides the standard axioms these depend on `Lean.ofReduceBool` and `Lean.trustCompiler`, i.e. compiled evaluation of Lean's LRAT checker, which is the usual trust base of `bv_decide`. The refutation is independently confirmed by drat-trim and by two SAT solvers.

**H = 5 (not settled).** The eager encoding generates O(n²·H) rank clauses and O(k²) monotonicity clauses, and it did not finish H = 5 within 30 minutes. The fully lazy variant `cut_ground2.py`, where every axiom family is added only when the model violates it and the height bound becomes direct "no chain of H + 2 elements" clauses, reproduces H ≤ 3 but has a higher per-round cost. The next tool is the **height induction**. A minimal counterexample of edge-height H has no proper F-stable interval [p, q] with p ∈ D, q ∉ D: p ≤ F(p,p) and F(q,q) ≤ q make [p, q] F-stable, a counterexample of smaller edge-height, because a chain in [p, ⊤] extends by ⊥. So, assuming the Cut Lemma at height H − 1, the clauses d(p) ∧ ¬d(q) ∧ p ≤ F(p,p) ∧ F(q,q) ≤ q ⇒ p = ⊥ ∧ q = ⊤ are sound at height H, and they compose with the per-level Lean certificates into an induction.

**Status (superseded by §34.3h).** CL and semi-CL hold on every complete lattice of edge-height ≤ 4. The log's named frontier lattices D_ω, M_ω × C₂ and E_ω are all settled. The open problem is now edge-height ≥ 5 and chain-finite lattices of unbounded height; for those the Cut Lemma, i.e. join-closure of R(F) (§34.4a), remains the single missing statement.

## 34.3h New: the Cut Lemma at edge-height ≤ 5; smaller certificates; no small finite poset counterexample

Two changes to the search of §34.3g settle H = 5 in seconds.

**(1) WLOG F(⊥, ⊤) ∉ D.** The order dual of a cut counterexample (α, F, D) is (αᵒᵈ, Fᵈ, Dᵈ) with Fᵈ(x, y) = F(y, x) and Dᵈ the complement of D, read in αᵒᵈ. It is again a cut counterexample: monotonicity, the down-set property and no-witness are preserved, and so is the chain bound. Moreover c = F(⊥, ⊤) satisfies Fᵈ(⊥ᵈ, ⊤ᵈ) = c, and c changes side. So the unit clause c ∉ D is sound (`run(wlog=True)`).
- Lean: `GroundCut.lean` proves `CutCx.dual`, `NoChain.dual` (via `chainTo_dual`: a chain ending at x in αᵒᵈ is a chain starting at x in α) and **`cut_of_wlog`**, which turns a refutation under c ∉ D, uniform in the poset, into a refutation of the theory.
- The generated core takes `hw : t 2 ∉ D` and closes with `cut_of_wlog`.

**(2) Tightness-guided term selection** (`run(room='fit')`, one term per round). For each candidate F(x, y) with x ∈ D, y ∉ D in the current model, count the places its value could go:
- existing elements z above every F(s, t) with s ≤ x, t ≤ y, below every F(s, t) with x ≤ s, y ≤ t, with z ≰ x and y ≰ z (no-witness);
- plus one if a fresh element fits between the longest model chains below and above it.

The tightest candidate is added, ties broken by depth. A candidate with no place refutes the model outright. This is the choice the hand proof of §34.3f makes: the next cell is the one the model can least afford. Depth-first selection (§34.3g) instead floods the instance with shallow terms that no refutation uses.

| H | depth-first (§34.3g) | + WLOG | + WLOG, tightness (1 term/round) | certificate core |
|---|---|---|---|---|
| 3 | 35 terms | 7 | 7 | 36 clauses / 7 terms |
| 4 | 388 terms, 58 s | 33 | **19 terms, 0.1 s** | 100 clauses / 17 terms (was 385 / 64) |
| 5 | ≥ 497 terms after 21 min, stopped | ≥ 382 after 5 min, stopped | **128 terms, 17 s** | **832 clauses / 86 terms** |

**H = 5, checks.**
- **Solvers:** CaDiCaL and Glucose both report UNSAT (334,141 clauses, 17,280 variables).
- **Certificate:** drat-trim verifies the Glucose DRAT proof. The core is 832 clauses over 86 terms, with 35 lemmas in 2,231 resolution steps.
- **Lean:** `cut_lean.py` turns the core into `lean/Mordor/CutHeight5.lean`, giving `Ground.cut_height5`: in every bounded poset with no chain of seven elements, every monotone F and every down-set D ∋ ⊥, ⊤ ∉ D have a witness cell. `Height5.lean` derives **`semi_height5` and `cl_height5`**. `bv_decide` takes 14 minutes on this container (the 100-clause H = 4 certificate: 11 s). Trust is as in §34.3g: `Lean.ofReduceBool` and `Lean.trustCompiler` besides the standard axioms; `cut_of_wlog` itself uses only the standard three.
- **Lazy height induction** (`lazy_ih=True`) adds, on violation and without new terms, the clauses "x ∈ D, x ≠ ⊥, s, t ≤ x ≤ F(s, t)" ⇒ ⊥ and dually. They are sound given the Cut Lemma one height down ([x, ⊤] would be a smaller counterexample). They change nothing at H ≤ 4 and are not needed at H = 5.

**Locality** (`Height5.lean`, `Ground.cut_local5`, `semi_local5`). The F-subalgebra ⟨⊥, ⊤⟩_F generated by the bounds is a bounded, F-closed subposet, and every down-set D of L restricts to a down-set of it. A witness found in the subalgebra is a witness in L. So the Cut Lemma for F, and with it semi-CL for F, holds on **any** complete lattice, whatever its height, as soon as ⟨⊥, ⊤⟩_F has no chain of seven elements. By Theorem A every complete lattice with an infinite chain has some F that violates CL; for such an F the subalgebra must contain a 7-chain.

**H = 4, re-certified.** The tightness run gives a core of 100 clauses over 17 terms, and `CutHeight4.lean` is regenerated from it.

**Finite models (`cut_finite.py`).** This is a direct SAT search for a finite cut counterexample in the poset version: n elements numbered by a linear extension, F one-hot with an order-encoded F(i, j) ≤ k, rank variables for the height bound, and WLOG c ∉ D. Results:
- no bounded poset with ≤ 11 elements carries a counterexample, at any height (n = 11: 124 s). That includes every lattice with ≤ 11 elements, which extends the ≤ 8 of §31.

Dropping either half of the no-witness axiom gives models at once, so the encoding is not vacuous. Two remarks:
- A finite poset counterexample at some height h would make the ground refutation at H = h impossible, and would mean lattice axioms are needed. None exists in this range.
- A minimal counterexample is generated by ⊥ and ⊤ under F, because the F-subalgebra generated by the bounds is a bounded F-closed subposet. So the term models of `cut_ground.py` lose no generality. The theory C_H^≤ is refutable iff it has no such model, finite or infinite.

**Status.** CL and semi-CL hold on every complete lattice of edge-height ≤ 5, in fact the Cut Lemma holds in every bounded poset of edge-height ≤ 5. The open problem is edge-height ≥ 6 and chain-finite lattices of unbounded height. The certificates grow (core terms 7 → 17 → 86 for H = 3, 4, 5, counting ⊥ and ⊤), so this route settles fixed heights, not the conjecture.

## 34.3i New: CL fails under M0 too; two foundation rows need qualifying (external review)

**B1 (Harmony) is false in a general category, as the review says.** In Set with F(X) = X + X and X = 1, the unique a : 2 → 1 and either injection c : 1 → 2 give a ∘ c = id with neither map an isomorphism, and 1 is not a fixed point of F. In a thin category, which is the lattice setting of all the research, B1 holds trivially: x ≤ F(x) ≤ x forces F(x) = x. So B1 is a theorem of the order-theoretic instance and an extra postulate elsewhere.

**I2 / I5 ("one-step commutation is a sufficient route"): the review's reason is incomplete, and this section completes it.** The review cites Theorem A. But the foundations assume M0, that F preserves ω-colimits and ω-limits of chains, and the counterexamples behind Sharpness and Theorem A violate M0. The ladder has F(x, ω) = s(x) while F(x, n) = x for all n < ω. So Theorem A alone does not refute I2 as the foundations state it. `Mordor/Continuous.lean` closes the gap. On ℕ∞ = ω + 1, take

  F(x, y) = min(x + 1, y ∸ 1),  with ω ± 1 = ω.

- F preserves sups of monotone sequences jointly (`F_iSup`). This works because y ↦ y ∸ 1 is a left adjoint of z ↦ z + 1, and min distributes over directed sups.
- F preserves infs of antitone sequences (`F_iInf`). This is automatic, since ℕ∞ is well-founded and infs are attained.
- The derived maps are a(x) = 0 for x < ω, a(ω) = ω (`a_F`), and b(y) = y ∸ 1 (`b_F`).
- So a ∘ b = b ∘ a (`comm`), while m = 0 ≠ ω = n (`cl_fails_continuous`). This uses only the standard axioms.

The infinite chain is the obstruction itself, not the discontinuity of the ladder: **M0 does not rescue one-step commutation.** By the Duality Theorem the order dual gives the same on 1 + ωᵒᵖ, since M0 is self-dual. Whether every complete lattice with an infinite chain admits an M0-continuous violator is open, because the retraction transfer of Theorem A (§23.1) need not preserve continuity. In the chain-finite lattices of the standing conjecture, M0 is vacuous.

## 34.3j New: which laws between the two powers force m = n; semi-CL is local to [m, n]

The source reading (`docs/02-the-source.md` §3.3) makes the hypothesis of CL a law between the two powers: λ : b ∘ a ⇒ a ∘ b. `experiments/dialgebra/laws.py` tests candidate laws exhaustively on C3 (175 F), C4 (24,696) and B2 (28,224). A law is *sound* if every F satisfying it has m = n.

| Law (all x unless restricted) | C3 holds / violators | C4 | B2 | Verdict |
|---|---|---|---|---|
| comm: a(b x) = b(a x) | 137 / 0 | 12,450 / 0 | 15,984 / 0 | sound (CL) |
| semi: b(a x) ≤ a(b x) | 143 / 0 | 13,614 / 0 | 16,276 / 0 | sound (semi-CL) |
| **semi on [m, n] only** | **155 / 0** | **17,416 / 0** | **20,032 / 0** | **sound, and holds exactly when m = n** |
| semi on Fix a ∪ Fix b only | 163 / 20 | 21,294 / 7,280 | 25,868 / 8,192 | unsound |
| b(x ∧ a x) ≤ a(T_b x) (GSOS-style; T_b the closure of b) | 175 / 20 | 24,696 / 7,280 | 28,224 / 8,192 | holds for every F: no content |
| T_b ∘ D_a ≤ D_a ∘ T_b (closure/interior) | 175 / 20 | 24,696 / 7,280 | 28,224 / 8,192 | holds for every F: no content |
| on Fix a ∩ [m, n]: b z ≤ z | all / 20 | all / 7,280 | all / 8,192 | a theorem: F(z, z) = F(z, a z) = a z |

The total counts of F with m ≠ n are 20, 7,280 and 8,192, so "violators = that count" means the law excludes nothing. Like the single-functor law of §34.3h's source reading, the GSOS-style and closure/interior laws are automatic, and the variants without T_b (b(x ∧ a x) ≤ a x, b(x ∧ a x) ≤ x) are not.

**Why the two laws are automatic (`Axioms.Source.cross`, `gsos_law`, `clint_law`).** The search isolated one lemma.

*Cross lemma.* If y ≤ a(z) and b(y) ≤ z, then b(y) ≤ a(z).

*Proof.* Let s = b(y) ∨ a(z). Then F(z, s) ≥ F(b y, y) = b(y) and F(z, s) ≥ F(z, a z) = a(z). So s ≤ F(z, s), hence s ≤ a(z). ∎

- The GSOS-style law is the case y = x ∧ a(x), z = T_b(x).
- For the closure/interior law, t = T_b(D_a x) is the least b-closed element above D_a x. The cross lemma makes t ∧ a(t) b-closed above D_a x as well, so t ≤ a(t), and cofreeness gives t ≤ D_a(T_b x).

These laws hold for every F on every complete lattice. N5 (31,022,611 F) confirms that the variants without T_b fail there too.

**Theorem (locality of semi-CL; `Local.semi_interval`).** If semi-CL holds on the complete lattice [m, n], then

  m = n  ⟺  b(a(x)) ≤ a(b(x)) for every x ∈ [m, n].

*Proof.* a and b map [m, n] into itself (L1, L2, I1), and F maps [m, n]² into [m, n] (F(m, m) = m, F(n, n) = n). The restriction G has derived maps the restrictions of a and b, with m_G = m and n_G = n (`restrict_mn`, via the embedding lemmas of `Restrict.lean`). Semi-commutation on [m, n] is semi-commutation of G, so m_G = n_G. ∎

**Corollary (`Local.semi_interval5`).** On every complete lattice of edge-height ≤ 5, m = n iff semi-commutation holds on [m, n]. The interval inherits the chain bound, and `semi_height5` applies.

So the hypothesis of the Commutation Lemma can be weakened to the gap [m, n] at no cost. The same holds for the guard: the Cut Lemma is needed only on [m, n]. Restricting further, to the fixed points of a or b, loses soundness.

## 34.3k External proposal: four proof strategies for the Bridge, tested

A second external review proposed four attacks on the Bridge (§7.6 of the foundations: R(F) is join-closed on chain-finite lattices). Each was checked.

**1. Derivation amalgamation**: x ∈ R_i, y ∈ R_j ⟹ x ∨ y ∈ R_{N(i,j)}, proved by induction on derivations. On a finite lattice some N always exists, so the content is whether N can be **uniform** (local). The *join delay* of F is max over x, y ∈ R(F) of s(x ∨ y) − max(s(x), s(y)), where s is the stage of first membership (`experiments/dialgebra/amalgam.py`, `amalgam_sample.py`, `amalgam_search.py`).

|---|---|---|
| C4, C5 (all F) | all 0 | all 0 |
| B2 (all 28,224 F) | 0: 17,472, 1: 10,752 | 0: 1,027, 1: 155, None: 114 |
| M3 (first 2·10⁶ F) | 0: 1,166,931, 1: 833,069 | 0: 21,079, 1: 4,642, 2: 597, None: 5,366 |
| N5 (first 2·10⁶ F) | 0: 952,023, 1: 1,047,977 | 0: 13,741, 1: 2,104, 2: 411, None: 2,240 |

- The F-structure matters. Arbitrary monotone pairs fail join-closure in 9–17 % of cases (the map-level shortcut fails, as in §31.3). F-derived pairs never failed in any sample.
- The tempting local form R_k ∨ R_k ⊆ R_{k+1} (delay ≤ 1) is **false**. Random F on the 6-element lattices give delay 2.
- A hill-climb maximising the delay finds 3 on L6_5 and E₂, and on the family C_k + side atom it finds 3, 4, 5 for k = 5, 6, 7 (n = 6, 7, 8). The search does not find comparable delays for larger k; the delay is shown to grow only up to 5, not unboundedly.
- Re-checked example (L6_5: chain 0 < 1 < 2 < 3 < 5 and atom 4): the atoms 1 and 4 enter at stage 1, and their join ⊤ enters at stage 4, the last.
- The mechanism is general: whenever two early elements join to ⊤, the delay is the time ⊤ takes to appear, which grows with height. So **no uniform N(i, j)**. The induction on derivations cannot close with a local step: the join of two derivations is available only once the closure is essentially complete.

**2. Well-founded induction on a rank of the "unresolved region."** No measure is proposed. The certificate sizes of §34.3h (core terms 7, 17, 86 for edge-height 3, 4, 5) indicate that any such rank must allow very fast growth in height. Not actionable as stated.

**3. Principalization** ("R(F) = L or R(F) is principal"). Under ACC every join of a subset is a finite join, so a nonempty down-set is join-closed iff it is principal. Principalization therefore *is* join-closure, restated. The review says as much ("essentially equivalent"). The data of strategy 1 show that intermediate stages R_k are routinely non-principal even when R(F) = L.

**4. μ/ν separation → a chain.** The k + j law (`CutDuality.k_plus_j`) already says the lower and upper closures meet at the same stage. Persistent separation is exactly a cut counterexample, and turning it into an infinite chain is the Bridge itself. A restatement.

**Accepted refinements.**
- The derived law b ∘ a ≤ a ∘ b is a plain distributive law of one functor over another: in a thin category it is a pointwise inequality. The coherence of a monad distributive law does not arise. Wording added (source §3.3).
- "Strict fusion holds exactly at principal stages" overstated the result. Equality is guaranteed on principal down-sets and, by `orbit_tight`, along the whole orbit on top-closed lattices. Fixed in the foundations (I6 row, §7.5).
- The root README still described v3.7 and edge-height ≤ 4. Synced.

## 34.3m New: finitely generated cuts, and the Cut Lemma on every finite lattice

**Setting.** A cut D of a bounded lattice L is *k × l-generated* when D = ↓{p₁, …, p_k} and L ∖ D = ↑{u₁, …, u_l}. No chain condition is assumed. Every cut of a finite lattice is generated by the maximal elements of D and the minimal elements of its complement.

**(i) Two dead ends first.**
- *Boundary witnesses.* "Some witness has x maximal in D or y minimal in U" sounded like a strengthening. It is equivalent to the Cut Lemma. A witness with F(x, y) ≤ x stays a witness when y moves down to a minimal element of U. One with y ≤ F(x, y) stays a witness when x moves up to a maximal element of D. (`experiments/sat/cut_finite.py --boundary`; `experiments/witness/`.)
- *Posets.* Finite generation alone does not suffice in posets. On ω ∪ {p, q, ⊤}, with D = ω ∪ {p, q}, take F(n, ⊤) = n + 1, F(p, ⊤) = q, F(q, ⊤) = p, and F = 0 elsewhere. This is a 2 × 1-generated counterexample. It is infinite: finite posets stay open, verified up to 11 elements (§34.3h).

**(ii) Ground refutation, no height bound** (`experiments/sat/cut_gen.py K L --lattice`). Add constants p_i (in D) and u_j (not in D), the two generation axioms, and meet constants for subsets of P and join constants for subsets of U. Without any chain axiom the theory is UNSAT for every k ≤ 4 with l ≤ 3, and for (2, 3).

**(iii) The labelling reduction** (`experiments/fgcut/labelling.py`; `lean/Mordor/FinGen.lean`).
- *Cells.* For nonempty A ⊆ [k] and B ⊆ [l], let z(A, B) = F(⋀p_A, ⋁u_B), α = {i : z ≤ p_i} and β = {j : u_j ≤ z}.
- *Constraints.* Exactly one of α, β is nonempty. No witness means α ⊉ A and β ⊉ B. Cell order is (A, B) ≤ (A′, B′) iff A ⊇ A′ and B ⊆ B′; along it α is antitone and β is monotone.
- *Soundness.* A counterexample yields such a labelling, so "no labelling for (k, l)" is the Cut Lemma for all k × l-generated cuts in all bounded lattices.
- *Machine results.* Labellings are UNSAT for k ≤ 3 with l ≤ 5, and for k = 4 with l ≤ 4.
- *Equivalence.* The labelling problem is exactly the Cut Lemma on the finite poset L_{k,l} = ⊥ ⊕ (nonempty subsets of [k], ordered by ⊇) ⊕ (nonempty subsets of [l], ordered by ⊆) ⊕ ⊤. Since the extension of F off D × U is free, the finitely generated lattice case reduces to one family of finite posets.
- *What the contradiction uses* (`variants.py`, `monotonicity.py`).
  - It survives dropping exclusivity: α ∪ β ≠ ∅ is enough.
  - It survives adding the boundary cells A = ∅ and B = ∅.
  - Every one of the four monotonicity directions is needed: dropping any one makes (2, 2) satisfiable.

**(iv) Lean: width ≤ 3** (`FinGen.lean`, `FinGen{11,…,33}.lean`, `FinGenWidth.lean`).
- `FinGen.lean` states a counterexample `Cx F D p u` and derives one clause lemma per labelling constraint.
- `experiments/fgcut/fg_lean.py K L` emits a CaDiCaL unsat core as `have`s, closed by `bv_decide`. The (3, 3) core has 310 clauses and checks in 85 s. The (4, 1), (1, 4), (4, 2) and (2, 4) cores also check. So do (4, 3) and (3, 4), with minimized cores of 740 and 753 of 3,472 clauses, in about 9 minutes each. Width ≤ 4 in Lean would also need (4, 4).
- `FinGenWidth.lean` proves:
  - `gens`: in a finite poset of width ≤ w, every nonempty set is generated by at most w maximal elements;
  - `cut_width3`: the Cut Lemma on every finite lattice of width ≤ 3, with no height bound;
  - `cutCells_width3`, `semi_width3`, `cl_width3`: semi-CL and CL on finite lattices of width ≤ 3.
- A chain-finite poset of finite width is finite by Dilworth, so `Finite` costs nothing against "chain-finite". Axioms are the standard three plus `Lean.ofReduceBool` (from `bv_decide`), as in §34.3g.

**(v) The general case: a product-KKM theorem (paper proof, not machine-checked).**

Put γ = [k] ∖ α and δ = [l] ∖ β. Then C¹_i = {cells with i ∈ γ} is an up-set, C²_j = {cells with j ∈ δ} is a down-set, and the constraints read:

> every cell (A, B) lies in some C¹_i with i ∈ A, and in some C²_j with j ∈ B; no cell lies in all of the C¹_i and all of the C²_j.

The cell poset is N_P × N_Q, with N_P the nonempty subsets of [k] under ⊇ and N_Q the nonempty subsets of [l] under ⊆. Its order complex realizes the simplotope S = Δ^{k−1} × Δ^{l−1}. Send the cell (A, B) to the pair of barycentres (b_A, b_B) and extend affinely over chains. This is the standard staircase triangulation of a product, so the map is a homeomorphism. `experiments/fgcut/tiling.py` checks this numerically for (2, 2), (2, 3), (3, 3) and (3, 4): every realized maximal chain is nondegenerate, and their volumes sum exactly to vol(S).

A point of S lies in the open simplex of exactly one chain c₀ < … < c_r, and supp s = A₀ and supp t = B_r. The up-set C¹_i contains the chain iff it contains c₀, and the down-set C²_j iff it contains c_r. So the closed sets K¹_i = |Δ(C¹_i)| and K²_j = |Δ(C²_j)| satisfy the KKM condition:

> every (s, t) ∈ S lies in some K¹_i with i ∈ supp s, and in some K²_j with j ∈ supp t.

*Product-KKM lemma.* Under that condition, ⋂_i K¹_i ∩ ⋂_j K²_j ≠ ∅.

*Proof.* Let I₁ = ⋂K¹_i and I₂ = ⋂K²_j, and suppose they are disjoint. Write d_i = dist(·, K¹_i), e_j = dist(·, K²_j), h₁ = dist(·, I₂) and h₂ = dist(·, I₁) (each ≡ 1 if the set is empty). Define

  T(s, t) = ( (d_i + h₁s_i) / (Σd + h₁) )_i , ( (e_j + h₂t_j) / (Σe + h₂) )_j.

The denominators are positive: Σd = 0 puts the point in I₁, hence outside I₂, so h₁ > 0. Brouwer gives a fixed point (s*, t*). Pick i ∈ supp s* with d_i = 0. The fixed-point equation gives s*_i Σd = 0, so Σd = 0 and the point lies in I₁. Symmetrically it lies in I₂, a contradiction. ∎

Back in the order complex, the common point's chain lies in every C¹_i and every C²_j. Any of its cells has α = β = ∅, which is impossible. Hence:

**Theorem (paper proof).**
- No (k, l) labelling exists, for any k and l.
- So the Cut Lemma holds for every finitely generated cut of every bounded lattice.
- In particular the Cut Lemma, and by `semi_of_cut` semi-CL and CL, hold on **every finite lattice**.

**Status.**
- The steps from cut to labelling and from Cut to CL are in Lean. Lean also has the theorem itself for width ≤ 3.
- The topological step uses Brouwer and the product triangulation, and Mathlib has neither. **Superseded by §34.3n:** a Sperner-type parity proof replaces the topology and is checked in Lean for all k and l.
- The proof uses no lattice structure beyond the meets ⋀p_A and joins ⋁u_B. It needs no chain condition.

**Consequence for the frontier (§34.4a).** The standing conjecture is settled on finite lattices. It stays open on infinite chain-finite lattices whose cuts need infinitely many generators (infinite width; edge-height ≤ 5 is already covered by §34.3h), and on finite posets.

**(vi) A poset generalization, by SAT** (`twoptr.py`, `gentpl.py`). The labelling, without exclusivity, is the case P = 2^[k], Q = (2^[l])ᵒᵖ of the following statement.

> **Two-pointer lemma.** Let P and Q be finite bounded posets, D₀ ⊊ P a down-set containing ⊥, and U₀ ⊊ Q an up-set containing ⊤. Let f : P × Q → P and g : P × Q → Q be monotone, with x ≰ f(x, y) and g(x, y) ≰ y on the interior (P ∖ D₀) × (Q ∖ U₀). Then some interior cell has f ∈ D₀ and g ∈ U₀.

- SAT confirms it on all 2,809 instances over seven small posets: chains, B₂, M₃, N₅, the bowtie, W and M.
- Several strengthenings are false: forcing the cell to an (atom, coatom) corner, to a prescribed atom or coatom, or to (⊤, ⊥). They hold only when the atom or coatom is unique, where the 1-D Kleene descent finishes the proof.
- The 1-D cases are exactly the (k, 1)-cycle argument.
- The product-KKM proof does not obviously extend to posets whose order complexes are not simplices.

## 34.3n New: a product Sperner lemma, and CL on every finite lattice in Lean

§34.3m(v) needed Brouwer. This section replaces it with a combinatorial parity argument, formalized in `lean/Mordor/Sperner.lean` (combinatorics) and `lean/Mordor/FinGenAll.lean` (application). Together they prove `Mordor.cl_finite`: **CL holds on every finite lattice.**

The axioms are `propext`, `Classical.choice` and `Quot.sound`. No `bv_decide`, no SAT certificate, no width or height bound.

**From covers to single labels.** Pick, at each cell c = (A, B), a label λ₁(c) ∈ A ∖ α(c) and a label λ₂(c) ∈ B ∖ β(c). These are Sperner labellings: λ₁(c) ∈ A, λ₂(c) ∈ B, and no monotonicity is needed. Call a maximal chain c₀ < c₁ < … < c_{k+l−2} *good* if:
- λ₁ is a bijection onto [k] on its first k cells, and
- λ₂ is a bijection onto [l] on its last l cells.

The pivot c_{k−1} is shared by both parts. α is antitone and β monotone along the chain, so the pivot of a good chain has α = β = ∅, which is impossible. It is enough to show that a good chain exists.

**Theorem (product Sperner lemma; `Sperner.odd_goods`, `exists_good`).** For every pair of Sperner labellings, the number of good maximal chains is odd.

SAT confirms existence for every (k, l) up to (3, 3), and for (2, 4) and (4, 2) (`sperner_sat.py`). Random labellings give only odd counts. `sperner_check.py` checks each step below on the exact Lean definitions.

**Proof.**

1. *Chains are words.* A maximal chain of N_P × N_Q is an ordering w of P ⊔ Q whose first letter is in Q and last letter in P. Its cells are the cells of its proper prefixes: A is the P-letters not yet read, B the Q-letters already read. Swapping the letters at positions t, t + 1 changes exactly cell t (`cells_sw`). This is the pseudomanifold structure: the swap is an involution on (word, deleted cell) pairs. It fails only when it would move a P-letter to the front (t = 0) or a Q-letter to the end (t = n − 2). Those are the boundary facets, and they lie on the faces A ∌ w₁ and B ∌ w_{n−2}.

2. *Doors.* Fix i₀ ∈ P (k ≥ 2). A facet is a *door* if it is good for (P ∖ i₀, Q): λ₁ bijective onto P ∖ i₀ on its first k − 1 cells, λ₂ onto Q on its last l. Every chain has a number of doors ≡ [chain good] (mod 2) (`doors`). The proof reduces to the removal lemma on the two label words (`removal`, `removal_P`, `removal_Q`):

   > deleting one letter of a word a leaves a multiset M (without repeats) an odd number of times iff a = M + {y} for some y ∉ M.

   The pivot needs care: deleting a cell shifts the boundary between the two words, which is handled by `take_eraseIdx` and `drop_eraseIdx`.

3. *Double counting.* Count pairs (word, door), mod 2 (`reduce`):
   - by words, the count is #good(P, Q), by step 2;
   - interior doors pair off under the swap (`Finset.sum_involution`);
   - a boundary door at t = n − 2 is impossible, since its cells miss a letter of Q;
   - a boundary door at t = 0 needs w₁ = i₀;
   - deleting that letter is a bijection onto the good words of (P ∖ i₀, Q) (`boundary`, `del1`, `ins1`).

   Hence #good(P, Q) ≡ #good(P ∖ i₀, Q).

4. *Base case* (`base`). For P = {i} there is exactly one good word. The top cell is ({i}, Q). Its label y forces the last Q-letter to be y, and deleting y gives the unique good word of ({i}, Q ∖ y), by induction on |Q|. ∎

Note that the barycentric flag Sperner lemma on a single simplex has exactly one fully labelled flag, the greedy one. So the single-simplex case is the minimal-element argument of the (k, 1) proof. The product genuinely needs parity, and the count is odd, not always 1.

**Application** (`FinGenAll.lab`, `cut_fingen`, `cut_finite`, `cutCells_finite`, `semi_finite`, `cl_finite`):
- every k × l-generated cut of every bounded lattice has a witness, for all k, l ≥ 1, with no chain condition;
- every cut of a finite lattice is finitely generated (`gens`), so the Cut Lemma holds on every finite lattice;
- with `semi_of_cut`, so do semi-CL and CL.

**What this settles and what it does not.**
- The standing conjecture, CL on chain-finite complete lattices, is now a theorem for finite lattices. It is a theorem for edge-height ≤ 5 (§34.3h), and for every lattice in which each cut and its complement are finitely generated.
- Open: chain-finite lattices of edge-height ≥ 6 in which some cut needs infinitely many generators. By Dilworth, a chain-finite lattice of finite width is finite, so these have infinite antichains.
- Open: finite posets, where the meets ⋀p_A that define the cells need not exist. The infinite poset counterexample of §34.3m(i) shows finite generation alone is not enough there.
- The bv_decide refutations of §34.3m(iv) remain as independent checks of the small cases.

**Files.** `lean/Mordor/Sperner.lean` (about 950 lines), `lean/Mordor/FinGenAll.lean`, `experiments/fgcut/sperner_check.py`, `sperner_sat.py`. `lake build Mordor.FinGenAll` builds from Mathlib in under two minutes, once the needed Mathlib modules are compiled.

## 34.3o External proposal, fourth round: captured tables, and a finite-closure criterion

An external review (ChatGPT), written against the repository just after §34.3n, proposes five "axioms" B1–B5 for the infinite-boundary case.

**B1–B3 are restatements, correct.**
- B1: under ACC + DCC, D = ↓Max(D) and its complement is ↑Min, possibly infinite.
- B2: the labelling of §34.3m(iii).
- B3: keep the cell table of F, not identities in a and b alone. This is the lesson of §34.3l.

**B4, the terminal step, is right and sharper than stated** (`FinGenAll.captured`, Lean, standard axioms). Call a finite table captured when each of its cells z(A, B) = F(⋀p_A, ⋁u_B) is either below some p_i (if in D) or above some u_j (if not). A captured table with no witness cell is contradictory. Two strengthenings over the review's version:
- The p_i ∈ D and u_j ∉ D can be any elements, not boundary generators.
- Only the Sperner pivot needs to be captured, since the proof never uses generation. `lab` (§34.3n) is now a corollary of `captured`.

**New consequence: a finite-closure criterion.**

> **Theorem** (`FinGenAll.cut_of_finite_closure`, `Mordor.semi_of_finite_closure`). If a finite set S contains ⊥ and ⊤ and is closed under ⊓, ⊔ and F, then every cut has a witness. So semi-CL holds for that F, on any complete lattice, with no chain condition.

*Proof.* Use S ∩ D and S ∖ D as the table. Every cell value lies in S and so captures itself. ∎

This is a per-F statement and needs no finiteness of L. It is consistent with Theorem A: the infinite-chain violators of §22–23 generate infinite closures; the ladder F(x, ω) = s(x) generates ω.

**A reduction that comes with it.** A counterexample on L restricts to the (⊓, ⊔, F)-subalgebra generated by {⊥, ⊤}:
- the restriction is a sublattice containing both bounds;
- D intersects it in a proper down-set, and no witness appears;
- it inherits chain-finiteness and is countable.

So the open case is: **countable chain-finite lattices generated by ⊥, ⊤ under ⊓, ⊔, F, of edge-height ≥ 6, with an infinite antichain.**

**B4 as a conjecture, and B5, need care.**
- B4 says every counterexample on a chain-finite lattice admits a captured table. Since captured tables are contradictory, this is the Cut Lemma on chain-finite lattices restated, not a weakening.
- B5 proposes refinement steps that terminate by an ordinal rank. The most natural refinement adds each uncaptured cell value to the table. Its fixpoint is exactly the (⊓, ⊔, F)-closure, and that closure can be infinite on chain-finite lattices where the Cut Lemma holds.
- Example (`experiments/fgcut/momega_closure.py`), on M_ω with atoms a_i:
  - F(⊥, ⊤) = a₀, and F(⊥, y) = ⊥ otherwise;
  - F(a_i, a_i) = a_{i+1}, F(a_i, a_j) = ⊥ for j ≠ i, F(a_i, ⊥) = ⊥, F(a_i, ⊤) = ⊤;
  - F(⊤, ⊥) = ⊥, and F(⊤, y) = ⊤ otherwise.
- This F is monotone (checked on every truncation tested), and the closure of {⊥, ⊤} is all of M_ω. The Cut Lemma holds there, since the height is 2.
- So a rank argument cannot measure progress toward closing the table. It must measure progress toward capturing the pivots, which depend on the chosen labels and can be captured by elements outside the table, such as maximal elements of D.
- The review's caveat stands: chain-finiteness alone does not stop infinitely many incomparable boundary generators.

**Type compression** (merging boundary generators with the same profile against the current table) is a heuristic for proof search, not a statement about lattices. It has no content to test until a candidate rank exists.

## 34.3p New: localization of the Cut Lemma (ideas from eat-the-fibre)

The companion project `kaol/eat-the-fibre` (Δ-compatible folds of path algebras) has the same architecture as this one:
- a rigid case proved (Theorem 1: no parallel arrows ⇒ finitely many folds);
- pathology from explicit configurations transported along substructures (Theorems 2–4 ↔ Theorem A and its retraction transfer);
- an open converse (Conjecture 3ᶜ ↔ chain-finite ⇒ CL).

Three of its methods were tried here:
- *stratify by how the decomposition interacts with the operation* (its module classes, v2.32);
- *hunt for a second mechanism once the first is characterized* (its 1⇉2⇇3 surprise, v2.27);
- *watch how a quantity scales across a family* (its q-polynomial orbit counts).

They give a localization calculus, machine-checked in `lean/Mordor/Localize.lean` with the standard axioms only.

**Confinement** (`confine`). Work in a box [s, t] with s ∈ D and t ∉ D, assume no witness among its cells, and let c = F(s, t) be its corner. Every cell value is pinned between two others: s < F(s, y) ≤ F(x, y) ≤ F(x, t) < t, with F(s, y) ≤ c ≤ F(x, t). So it lies in the corner neighbourhood

  V(c) = {z ∈ [s, t] : z ⊓ c ≠ s, z ⊔ c ≠ t}.

**Finite neighbourhoods ⟹ Cut, with no chain condition** (`cut_of_finite_nbhd`, `Mordor.semi_of_finite_nbhd`). Suppose every c ∉ {⊥, ⊤} has only finitely many z with z ⊓ c ≠ ⊥ and z ⊔ c ≠ ⊤. Then every cut of every monotone F has a witness, and semi-CL and CL hold. The proof captures every cell value by itself, through the finite-table lemma `capture_contra`, which generalizes §34.3o's `captured`.

Covered examples:
- Every horizontal sum ⊥ ⊕ (⊔ᵢ Lᵢ) ⊕ ⊤ of finite lattices, since V(c) lies in c's comparability component. This includes M_ω, E_ω and **Ω = ⊥ ⊕ (⊔ₙ Cₙ) ⊕ ⊤ (chains of every length side by side)**, a chain-finite lattice of unbounded height and infinite width that no earlier theorem reached.
- The zigzag of columns linked at their tops, which is connected.

**Moves** (`shrink_top`, `shrink_bot`, `spine_bot`, `spine_top`). The box can be changed:
- to [s, ⋁V] if the corner is outside D;
- to [⋀V, t] if the corner is inside D;
- by replacing an end with an interior spine point (one comparable with the whole box) on the matching side of the cut. This is the vertical-sum reduction, and here it is a single line, because a cell value below the spine point would be a witness.

**Localization theorem** (`cut_localize`). On a chain-finite complete lattice, well-founded recursion on boxes gives a witness unless some reachable box is *stuck*: no finite table captures V, neither shrink move applies, and there is no spine point. **Box criterion** (`cut_of_box_criterion`, `Mordor.semi_of_box_criterion`): a D-free sufficient condition. Every box has a spine point, or else every interior c has V finite, or ⋁V < t and ⋀V > s.

**Stratification.** If all cell values of a box lie outside D, then V ∩ D = ∅, and V ∩ U is captured by its minimal elements. Under DCC the pure stratum needs no finiteness at all: take y minimal outside D with F(s, y) ≤ y; it is a fixed point, hence a witness. The dual holds under ACC. So a counterexample is *mixed* at every reachable box, which is the analogue of eat-the-fibre's module classes.

**Size-uniformity experiment** (`experiments/localize/boxes.py`). Every (box, corner) pair is classified on truncations N = 4, 6, 8 of five infinite chain-finite families. A pair is *growing* if |V| increases with N, and *stuck (D-free)* if it is growing, has no spine point, and fails ⋁V < t or ⋀V > s.

| family | stable pairs | growing | stuck (D-free) | resolution |
|---|---|---|---|---|
| Ω | 35 | 0 | 0 | finite neighbourhoods |
| zigzag | 82 | 0 | 0 | finite neighbourhoods |
| H∞ = Ω + hub h above every column + k above (1,1) | 69 | 1 | 1: [⊥, ⊤], c = h, ⋁V = h < ⊤, ⋀V = ⊥ | D-dependent. h ∉ D: shrink to [⊥, h], a horizontal sum. h ∈ D: V ∩ D has the single maximum h, so capture |
| S∞: ⊥ < d < c, chains Zᵢ (length i) above d, wᵢ = c ∨ top Zᵢ | 133 | 3 | 1: [d, ⊤], c | d is a spine point. In [d, ⊤]: c ∉ D gives V = {c, wᵢ} ⊆ U, captured by c; c ∈ D gives ⋀V = c, so shrink |
| **S∞′ = S∞ + a second atom e < c** | 148 | 5 | 4, among them [⊥, ⊤] with corner c: V = everything, ⋁V = ⊤, ⋀V = ⊥, no spine | **stuck** whenever F(⊥, ⊤) = c and D cuts infinitely many chains |

**S∞′ is where the calculus gives out.** It is chain-finite, of unbounded height, and not fin-gen, with no spine and no small neighbourhoods. So it is a concrete test bed for the standing conjecture, as 1⇉2⇇3 was for Conjecture 3ᵛ.

A hand attempt at a counterexample on S∞′ fails in an instructive way. With F(⊥, ⊤) = c ∉ D and d ∈ D, the no-witness constraints force:
- F(⊥, c) = d;
- F(d, c) into a single chain Z_k;
- F(x, ⊤) = w_k for every x ∈ D above d.

The problem then collapses onto the finite chain Z_k, where a witness is forced. This points to a refinement: localize at *rectangles* x ∈ [s₁, t₁], y ∈ [s₂, t₂] with corners such as F(d, ⊤), not only at boxes with corner F(s, t). Neither a proof of Cut on S∞′ nor a counterexample exists yet.

**Updated frontier.** CL is open only on chain-finite lattices where the localization calculus gets stuck. Such a lattice has a box with no spine point and a corner whose neighbourhood both spans the box on the relevant side and has infinitely many boundary elements. S∞′ is the smallest family found.

## 34.3q External framework: "The Anarchist Bialgebra" read for proof strategy

The framework's formal [F] layer is a commutative Hopf-algebra fragment. Its own witness model is (ℤ₅)³, and it carries no order structure, so it has no direct content for lattices. Its procedural rules were read as proof heuristics and tested against the stuck family S∞′ of §34.3p.

**Locality (P3a "no object reads the global state", ρ6 "smallest containing federation")** → near/far abstraction (`experiments/localize/nearfar.py`). Constrain only the cells built from a fixed finite near region: ⊥, d, e, c, ⊤ and the first M chains. Far chains are anonymous long chains, since any far chain looks like any other from the near region.
- **Result:** SAT for every (M, K, L) tried. D swallows the near region, U ∩ near = {⊤}, and all witnesses sit at far cells.
- So no fixed finite region forces a witness on S∞′. Any localization must depend on F and D, as the box calculus of §34.3p does.

**Blocs (β3d: individually small, collectively dominating)** → the chains Zᵢ form a bloc whose only access to the hub c is through d. A hand case analysis, with corner F(⊥, ⊤) = c ∉ D and d, e ∈ D:
- **F(d, ⊤) = c.** Then F(d, c) = e is forced, since it is the only point of ↓c outside ↓d ∪ ↑c.
  - If also F(e, ⊤) = c, then F(e, c) = d, and the table {⊥, d, e} × {c, ⊤} captures all six cells. So `captured` forces a witness.
- **F(d, ⊤) = w_k.** Every cell with x ≥ d is bounded by w_k, and the capture closure stays inside the finite ideal ↓w_k ∪ {⊤}, so a witness exists.
- **Remaining case:** chain-hopping. F(·, ⊤) sends Zₘ ∩ D to w_{σ(m)} with infinite σ-orbits. Only this can escape capture: it would imitate Theorem A's infinite chain with finite chains of growing length.

**Escape test** (`experiments/localize/escape.py`). On truncations S∞′_N, allow witnesses only at cells meeting the last chain.
- **Result:** SAT for N = 2, …, 7. Every solution is degenerate: D = L ∖ {⊤}, and F(d, ⊤) points into the protected last chain.
- On the infinite lattice that cut is principal on the upper side and is excluded by `cut_principal_up` (ACC).
- **Lesson:** a truncation with a protected boundary simulates an infinite ascending chain, so it cannot test well-foundedness.

This is the counterpart of the framework's own E3 finding ("review, the coinductive re-derivation, is load-bearing; caps alone are not"). Here well-founded induction is load-bearing, and finite truncation alone is not.

**Ratchet (β6b′: caretaker powers shrink monotonically, terms non-renewable)** → the form a proof of the hopping case must take. Attach to each hop m → σ(m) a quantity that strictly increases in a well-founded order of the lattice, for example the D-boundary position read through F(·, c) or F(·, ⊤). Then ACC/DCC stops the orbit, as `cut_principal_up` does for a single chain. The framework's E4 caveat transfers too: the ratchet must come with an escalation (here, capture once the orbit closes), otherwise it only shows the orbit is not periodic. Not yet done.

## 34.3r New: the ratchet, pinning, and the Cut Lemma on S∞′

§34.3q left one way to escape on S∞′: F(·, ⊤) hops from chain to chain with an infinite orbit. The ratchet that stops it is monotonicity through a common base. Every chain sits above d, so one *anchor* cell (d, y₀) bounds F(x, ⊤) from below for every x ∈ D above d. If the anchor's value has a finite up-set, F(x, ⊤) has finitely many values, and so do all cell values. There is nothing to hop between. Formalized in `lean/Mordor/Pin.lean`, standard axioms only:

- **`cut_of_values_in_finite`.** If, under no witness, all cell values F(x, y) (x ∈ D, y ∉ D) lie in a finite set, there is a witness. The proof captures each value by itself (`capture_contra`).
- **`cut_of_end_finite`, `Mordor.semi_of_end_finite`.** Call a lattice *end-finite* if every principal ideal ↓g (g ≠ ⊤) and every principal filter ↑g (g ≠ ⊥) is finite. On an end-finite lattice the Cut Lemma, semi-CL and CL hold, with no chain condition stated. The proof: cell values lie below F(x, ⊤) ∈ ↑F(⊥, ⊤) ∖ {⊤}. This **strictly generalizes the finite-neighbourhood theorem** of §34.3p, since ↑c ∪ ↓c ⊆ N(c) ∪ {⊥, ⊤}.
- **`pin_coatom`.** If F(x₀, y₀) ⊔ F(⊥, ⊤) is a coatom t, then F(x, ⊤) = t for every x ∈ D above x₀.
- **`cut_of_orbit_capture`.** This is the "escalation" step. In a lattice whose proper principal ideals are finite, take a finite set T ⊆ D that contains ⊥, is closed under ⊓, and captures every D-element below F(x, ⊤) for x ∈ T. Then there is a witness. A ratchet argument must end here: the D-orbit x ↦ ↓F(x, ⊤) ∩ D has to close.
- **`cut_hub`.** The Cut Lemma holds on every bounded lattice of *hub shape*:
  - proper principal ideals are finite;
  - only ⊥, d, e, c have infinite principal filters;
  - every element is ⊥, e, or above d;
  - ↓e = {⊥, e}, ↓c ⊆ ↓d ∪ {e, c}, ↑e ⊆ {e} ∪ ↑c, and e ≰ d;
  - the elements strictly between c and ⊤ are coatoms, and below such a coatom w every element is below c, equal to w, or has only ⊥ and d (among ⊥, d, e, c) beneath it.

  The proof:
  - If some anchor (d, y₀) has a value outside {⊥, d, e, c}, its up-set is finite, which pins F(x, ⊤) for every x ≥ d and leaves finitely many cell values.
  - Otherwise F(d, ⊤) ∈ {e, c}. The cells (⊥, c), (e, c), or (c, w), (d, w) with w = F(c, ⊤), are then forced into a witness.

**S∞′ satisfies the Cut Lemma.** It has hub shape:
- `experiments/localize/hub_check.py` checks every local hypothesis exactly on the truncations S∞′₃ … S∞′₈.
- The finiteness hypotheses are checked by stability: |↓g| is independent of N for every g, and only c, d, e (besides ⊥) have growing up-sets.
- Both checks are uniform in N, so they hold on the infinite lattice.

The family on which the localization calculus of §34.3p got stuck is therefore settled: neither a counterexample nor a gap. Lean checks `cut_hub` itself. The instance S∞′ is not built in Lean, since it is a non-distributive infinite lattice given by hand; the check is the script plus the uniformity argument.

**Where this leaves the frontier.**
- End-finite lattices are settled, and so are hub-shaped ones.
- A counterexample on an ideal-finite lattice needs an infinite D-orbit (`cut_of_orbit_capture`). The ratchet must fail at every anchor: every anchor value must keep F(·, ⊤) inside the elements with infinite filters.
- On S∞′ there are four such elements, and local structure forces a witness. Whether *finitely many* elements with infinite principal filters (plus finite ideals) always suffices is open. It is the natural next conjecture.
- The remaining candidates for a second mechanism therefore have infinitely many elements with infinite principal filters ("infinitely many hubs"), or infinite principal ideals.

## 34.3s New: the reset lemma — finitely many hubs suffice

§34.3r stated as its next conjecture that finite principal ideals plus finitely many *hubs* (elements with an infinite principal filter) give Cut. That conjecture is now **proved**, uniformly, with no shape hypotheses. The proof is shorter than `cut_hub`, which it subsumes. Formalized in `lean/Mordor/Hubs.lean`, standard axioms only.

**Reset lemma** (`cut_of_region`). Assume no witness. Suppose every cell value lies in a region R, and there is a finite A ∋ ⊥ such that inside R:
- every principal ideal ↓g ∩ R (g ≠ ⊤) is finite;
- every principal filter ↑g ∩ R (g ∉ A) is finite.

Then there is a witness after all. The proof modifies F instead of capturing it. (Refined in §34.3t: the filter condition is needed only for g ∈ D, and the structural part of the proof is factored out as `reset_core`.)
- *Bad rows.* An anchor row h ∈ A ∩ D is *bad* if all of its cell values lie in A.
- *Free and pinned rows.* A row x ∉ A ∪ {⊤} is *free* if every anchor below it is bad. Otherwise it is *pinned*.
- **Pinned rows.** A non-bad anchor h ≤ x has a cell value ℓ ∉ A. Then F(x, ⊤) ∈ ↑ℓ ∩ R, which is finite. This is the ratchet of §34.3r with an arbitrary anchor.
- **Free rows are reset** to G(x, y) = ⋁_{h ∈ ↓x ∩ A} F(h, y). Then G is monotone: a non-free row below a free one lies in A, hence is one of the joinands. G is also witness-free:
  - y ≤ G(x, y) would give y ≤ F(k, y) with k = ⋁(↓x ∩ A) ≤ x, so k ∈ D.
  - G(x, y) ≤ x would make h ↦ F(h, y) a monotone self-map of the finite set ↓x ∩ A, since bad rows have values in A. Its Kleene chain from ⊥ reaches a fixed point h = F(h, y), a witness. In Lean this is a maximal element of {h ∈ ↓x ∩ A : h ≤ F(h, y)}.
- After the reset, G has finitely many cell values:
  - anchor rows: ↓F(h, ⊤) ∩ R;
  - free rows: joins of subsets of these;
  - pinned rows: ↓s ∩ R for s ∈ ↑ℓ ∩ R.

  So `cut_of_values_in_finite` gives a witness of G, which contradicts what was just shown.

The reset is the point. Capturing (§34.3o–r) needed the D-orbit to close (`cut_of_orbit_capture`). Free rows can have infinite orbits under F, but under G their values are those of finitely many anchor rows. Infinite orbits of F through free rows are therefore no obstruction: the reset discards them without ever creating a witness.

**Corollaries** (all with semi-CL and CL on complete lattices):
- **`cut_of_finite_hubs`, `Mordor.semi_of_finite_hubs`.** Finite proper principal ideals and finitely many hubs give Cut. Take R = L and A = {⊥} ∪ hubs. This contains `cut_of_end_finite` (no hubs) and `cut_hub` (S∞′, hubs d, e, c).
- **`cut_of_finite_hubs_dual`, `cut_of_region_dual`, `Mordor.semi_of_finite_hubs_dual`.** These are the order duals: finite proper principal filters, and finitely many elements with an infinite principal ideal. Cut is self-dual per F once the arguments are swapped: on Lᵒᵈ take the cut U and F′(x, y) = F(y, x), and witnesses correspond.
- **`cut_of_nbhd_hubs`, `Mordor.semi_of_nbhd_hubs`.** No chain condition is needed. It is enough that every corner neighbourhood N(c) = {z : z ⊓ c ≠ ⊥, z ⊔ c ≠ ⊤} satisfies the hub condition relative to N(c), on one side or the other, chosen per c. Here R = N(F(⊥, ⊤)), by confinement (§34.3p). This contains `cut_of_finite_nbhd`.
  - It reaches lattices with **infinitely many hubs**: for example ⊥ ⊕ (⊔ᵢ Lᵢ) ⊕ ⊤ where each Lᵢ is a copy of S∞′ or of its dual, mixed freely.
  - Here the neighbourhood of c ∈ Lᵢ lies inside Lᵢ.

**Consistency with Theorem A.** On ω + 1, every proper ideal is finite, but every element is a hub. For c = n, the neighbourhood N(n) = [1, ω) has infinitely many relative hubs and infinite relative filters, so neither side of the hypothesis holds, as it must not.

**Where this leaves the frontier.** Cut, and with it CL, is now proved on every bounded lattice in which some side of the hub condition holds in every corner neighbourhood. A counterexample to the standing conjecture needs a chain-finite lattice and a corner c whose neighbourhood fails on both sides. That means:
- N(c) contains an infinite principal ideal, or infinitely many infinite principal filters; and
- N(c) contains an infinite principal filter, or infinitely many infinite principal ideals.

There is also the localization calculus (§34.3p), which can still split such a neighbourhood into boxes. The reset lemma is stated for a bounded lattice. Running it inside a box [s, t] needs the interval as a bounded lattice; it has not yet been wired into `cut_localize` as a halting alternative.

## 34.3t New: finite principal ideals and ACC — Cut on every such lattice

The reset of §34.3s pins a row to the up-set of one anchor value. Iterating it settles every lattice with finite proper principal ideals and no infinite ascending chain. No hub count is needed. Formalized in `lean/Mordor/IdealFinite.lean`, standard axioms only.

**Theorem** (`cut_of_ideal_finite`). Let L be a bounded lattice whose proper principal ideals are finite and which satisfies ACC. Then every cut of every monotone F has a witness. Dually (`cut_of_filter_finite`): finite proper principal filters and DCC suffice.

**Corollary** (`Mordor.semi_of_chainFinite_ideal`, `Mordor.semi_of_chainFinite_filter`). Semi-CL, hence CL, holds on every chain-finite complete lattice with finite proper principal ideals, or with finite proper principal filters. This proves the standing conjecture for these two classes.

These classes contain §34.3r–s, because finitely many hubs force ACC: an ascending chain consists of hubs. They also contain the rank-2 family R2 below, on which the box criterion stalls.

**Proof.**
- *Regions.* Let reg(S, N) = ↓S ∪ ⋃_{m ∈ N} R_m, with S, N finite and R_m = {y : y ≤ z for some z ≠ ⊤ with z ≥ m}.
- *Induction claim.* If, under no witness, every cell value lies in reg(S, N), then there is a witness after all.
- *Base case.* At N = ∅ the values lie in the finite set ↓S (`cut_of_values_in_finite`).
- *Step.* Reset (`Hubs.reset_core`) with the finite anchor set A = {⊥} ∪ ↓S ∪ ⋃_{m∈N} ↓m. For the reset bifunction G:
  - *Joins of anchor rows.* Their values are joins of elements of ↓F(h, ⊤) over h ∈ A ∩ D, so finitely many. They form the new S′.
  - *Pinned rows x.* An anchor h ≤ x has a D-valued cell ℓ = F(h, y₀) ∉ A, and ℓ ≤ F(x, ⊤).
    - F(x, ⊤) cannot lie in ↓S: then ℓ ∈ ↓S ⊆ A.
    - So F(x, ⊤) ≤ z for some z ≠ ⊤ with z ≥ m ∈ N, hence z ≥ m ⊔ ℓ. The row's values lie in R_{m⊔ℓ}.
    - m < m ⊔ ℓ, because ℓ ∉ ↓m ⊆ A.
  - So G has its values in reg(S′, N′), where every element of N′ lies strictly above an element of N.
- *Termination.* The relation "N′ lifts N" (`Lift`) embeds into the Dershowitz–Manna order on multisets over Lᵒᵈ. That order is well-founded by ACC (Mathlib's `Multiset.wellFounded_isDershowitzMannaLT`). The induction starts from S = ∅, N = {⊥}.

**Box versions and the merged criterion.**
- `box_ideal_finite` and `box_filter_finite` apply the theorem to an interval [s, t] (F clamped to (F ⊔ s) ⊓ t).
- `Hubs.box_reset` and `Hubs.box_reset_dual` do the same for the reset lemma relative to the corner neighbourhood V.
- `cut_localize` now takes a plain `False` as its closing alternative, so any of these closes a box.
- **`cut_of_box_hub_criterion`, `Mordor.semi_of_box_hub_criterion`** (chain-finite): every box [s, t] with interior c must satisfy one of the following:
  - it has an interior spine point;
  - its intervals [s, g] (g < t) are all finite;
  - its intervals [g, t] (g > s) are all finite;
  - both of these hold:
    - (*case c ∈ D*) ⋀W > s, or W has finite filters and finitely many g ≰ c with an infinite ideal;
    - (*case c ∉ D*) ⋁W < t, or W has finite ideals and finitely many g ≱ c with an infinite filter.

  The D-awareness comes from the refined reset: only hubs in D, or co-hubs in U, matter, and c ∉ D keeps D below the elements ≱ c. This criterion contains the box criterion of §34.3p.

**Experiments.**
- `experiments/localize/rank2_check.py`. R2 is S∞′ with a second layer of hubs h_i (each carrying chains of every length) and v_i = h_i ∨ c. Its corner neighbourhoods at d and c contain infinitely many hubs. The reset alternatives of the box criterion fail on 5 of 179 classes, including [⊥, ⊤] with corner c. R2 has finite proper ideals and is chain-finite, so `cut_of_ideal_finite` settles it anyway.
- `experiments/localize/products_check.py`.
  - Ω × C₂ fails the box criterion at [⊥, ⊤], but every corner neighbourhood satisfies the hub condition on one side (0 of 14 corners fail), so `cut_of_nbhd_hubs` covers it.
  - **Ω × Ω** fails the hub condition on both sides at every corner (23 of 23 on the truncations), for example at c = (⊤, ⊥). It is a chain-finite product of two end-finite lattices, with infinite proper ideals ((⊤, y)) and infinite proper filters ((x, ⊥)).

**Where this leaves the frontier.** Cut is open only on chain-finite lattices that have both an infinite proper principal ideal and an infinite proper principal filter, where moreover no reachable box closes by the criteria above. Finite posets remain open too. The cleanest test case is **Ω × Ω**; more generally, products L₁ × L₂ of lattices covered by the theorems above. No product theorem for Cut is known.

## 34.3u External framework: "The Cat Bialgebra" read for proof strategy

The framework is a categorical toy on **Set**:
- the stream functor B(X) = 1 + M × X with its sandwich μB ⊆ ρB ⊆ νB;
- a free monad T and a cofree comonad D joined by a distributive law λ : TD ⇒ DT, with bialgebras c ∘ a = D(a) ∘ λ ∘ T(c);
- recursion schemes, truncation comonads D_n, Burnside counts, trace measures, and dialgebra products (E17′, E19).

It has no order structure, so as with §34.3q only structural analogies can transfer. Each was tested against the current frontier, products such as Ω × Ω (§34.3t).

**1. E17′ / E19 (dialgebra products, the kernel lemma) → Cut on products.** E19 shows that products fail in Dialg(Obs, Real) because Real(X) = X + X is a disjunction. Two cones can land in different summands, so no carrier does the bookkeeping. The Cut witness F(x, y) ≤ x ∨ y ≤ F(x, y) is exactly such a disjunctive observation. On L₁ × L₂ a cell can be "inl in coordinate 1 and inr in coordinate 2" without being a witness.

*Prediction:* Cut on a product cannot be reduced to Cut on axis-parallel slices {b} × L₂ or L₁ × {a}, solving each and lifting.

*Test* (`experiments/products/slice_sat.py`, CaDiCaL). For each cut D of a finite product, search for a monotone F with no witness on any slice (x₁ = y₁ or x₂ = y₂).
- C₂ × C₂: 2 of 4 cuts admit such an F.
- C₃ × C₃: 14 of 18 cuts.
- M₃ × C₂: 35 of 44 cuts.
- M₃ × M₃: all 40 sampled cuts (out of 4386).

A complementary run forbids every witness comparable in some coordinate (x₁ ≤≥ y₁ or x₂ ≤≥ y₂). This leaves only doubly incomparable cells, which in M₃ × M₃ have distinct atoms in both coordinates. It is UNSAT for all 44 cuts of M₃ × C₂ (vacuous there, since every pair is comparable in the C₂ coordinate) and for all 40 sampled cuts of M₃ × M₃. That is weak, since every cell with a ⊥ or ⊤ coordinate counts as comparable. The two encodings (one-hot and order) agree on every case run with both.

Since finite lattices satisfy Cut (`cl_finite`), witnesses still exist, but only off the slices: the slice problems' witnesses do not lift. **Confirmed:** any proof of Cut on Ω × Ω, or a product theorem, must be genuinely two-dimensional. The finite case shows what that looks like: there the obstruction is beaten globally, by the product Sperner lemma of §34.3n, not by a local lax map. That is consistent with E19's moral: the product exists for reasons no projection can see.

**2. λ : TD ⇒ DT (bialgebras) → two-sided reset.** The reset of §34.3s–t is the free-algebra side: a row becomes a join of anchor rows. Its order dual, a column becoming a meet of co-anchor columns, is the cofree side. The composite, row reset (`reset_core`) and then column reset of the result, is monotone and witness-free, since each step is. On cells whose row is free and whose column is co-free, the composite takes the values ⋀_{h′ ∈ Q} ⋁_{h ∈ P} F(h, h′) over subsets P, Q of the finite anchor sets. These are **finitely many with no lattice hypothesis at all**, the analogue of the bialgebra law fixing everything on generators. What remains are pinned rows and co-pinned columns. Their values lie in intervals [w, v] with w = F(⊥, y) ≠ ⊥ and v = F(x, ⊤) ≠ ⊤.
- On lattices where such intervals are finite, both sides pin.
- On **Ω × Ω** they need not be: w = (⊥, a), v = (⊤, b) gives [⊥, ⊤] × [a, b].

So the two-sided reset locates the obstruction exactly: cells where one coordinate stays completely free while the other is pinned. A product theorem has to run a fibred induction there, pinning one coordinate and then solving the free one, and item 1 says it cannot do this slice by slice. The composite is not separately formalized: it is `reset_core` followed by its order dual.

**3. Remaining items.**
- Truncation comonads D_n with the limit level open (I8) restate the known limitation of truncation proxies (§34.3p, §34.3q).
- ρB as the locally finite core (O3′) restates the finite-closure criterion (§34.3o). It also suggests the folding remark: a counterexample with a periodic ("rational") shape folds to a finite one, so cannot exist. Ω × Ω has no such symmetry, since its chains all have different lengths.
- Burnside / excess (E12–E14), trace measures (E2–E4) and Tambara modules (E6′) have no counterpart here.

**Verdict.** The framework supplies no proof. It does supply one correct prediction: E19's kernel lemma, which SAT confirms. That prediction rules out a natural strategy for the frontier, factor-wise reduction on products. One reframing, the reset as the algebra half of a distributive law, isolates the free-coordinate cells as the precise remaining obstruction on Ω × Ω.

## 34.3v External framework: "Bialgebraic Axioms for Double-Entry Closing" read for proof strategy

The framework's mathematics:
- linear conservation, ε ∘ p = 0 on V = ℤ^A, with the chain complex 0 → J → V → ℤ → 0;
- an initial algebra of closing schedules and a Mealy ledger coalgebra;
- the same abstract-GSOS distributive law as §34.3u;
- a kernel-pair / coequalizer factorization of the period fold;
- a Banach contraction theorem for consolidation;
- allocation maps with ε ∘ A₁ = ε;
- a rank argument on a classification DAG.

Each item was read against the current frontier, products such as Ω × Ω.
- **Conservation / chain complex ↔ Sperner parity.** The finite Cut proof *is* a conservation law: `Sperner.odd_goods` counts good chains mod 2 by door pairing, and `captured` applies it to finite tables. A parity invariant needs finite support. On infinite lattices that support is exactly what the reset (§34.3s–t) manufactures, by forcing finitely many cell values. The analogy reproduces the existing architecture (finite support, then parity) and offers no new route to finite support on Ω × Ω.
- **Allocation, ε ∘ A₁ = ε ↔ the reset.** A reset is an operator on bifunctions that preserves the invariant "monotone and witness-free", as an allocation preserves ε. This is an interpretation only.
- **μ4 / B2 (termination by DAG rank, cascade bound = height) ↔ the Dershowitz–Manna induction of §34.3t.** Generators after k rounds lie strictly atop a chain ⊥ = m₀ < m₁ < … < m_k (each new generator is m ⊔ ℓ > m). So on a lattice of finite height h the induction ends after at most h + 1 resets: a cascade bound, quantitative but not new in kind.
- **Kernel pair / coequalizer (sampling is valid only with a characterized kernel) ↔ descent of Cut along quotients.** A counterexample would fold to a finite one along a congruence that the witness relation reflects (the "rational" remark of §34.3u). Ω has no lattice congruence onto a finite lattice that keeps distinct chains apart, because joins across chains are ⊤. So this does not reach Ω × Ω.
- **§17 multi-tier consolidation (Beck–Chevalley interchange) ↔ coordinatewise resets on L₁ × L₂.** A reset with anchors A₁ × L₂ is structurally valid in a chain-finite complete product: its joins are finite, over (a, x₂) with a ∈ ↓x₁ ∩ A₁. Running it, and then a second-coordinate reset with anchors L₁ × A₂, keeps first coordinates in a finite join-closed set. The induction breaks at the second stage: its anchor rows (x₁, a₂) are infinitely many, so the non-bad anchors, and with them the new generators, need not be finite. This is the fibred form of the obstruction isolated in §34.3u item 2.
- **Contraction theorem, DL coherence diagrams, time-indexed ledgers.** No order-theoretic counterpart, or already covered by §34.3u.

On finite lattices every one of these devices is vacuous for testing: they act on a witness-free F, and on finite lattices none exists (`cl_finite`). So no SAT experiment discriminates here.

**Verdict.** The framework does not help with the frontier. Its one structural echo, conservation as a parity invariant needing finite support, restates why the proof architecture is "manufacture finite support, then count", and why Ω × Ω is hard: neither one-sided reset manufactures it there.

## 34.3w New: the two-sided reset, and the frontier shrinks to Ω × C₃

Prompted by an outside proposal: "pin signatures" and a "finite-fibre theorem" for L × K with K finite. Both aim at the cells where one coordinate escapes while the other is pinned. Checking them gave three results.

**1. The frontier is smaller than Ω × Ω.** Ω × C₂ is covered (§34.3t), but **Ω × C₃** fails the neighbourhood hub condition on both sides at 8 of its 22 corners on the truncations, all of the form (z, 1), with 1 the middle of C₃. Ω × M₃ fails at 15 of 23 corners. Ω × C₃ fails the box criterion at [⊥, ⊤] too (`experiments/localize/products_check.py`, run on these families). So the finite-fibre theorem is exactly the missing piece, and **Ω × C₃** is the smallest test case: chain-finite, of unbounded height, with exactly three hubs (⊥, 0), (⊥, 1), (⊥, 2) and three co-hubs.

**2. Pin signatures, sharpened.** For x ∈ D and y ∉ D, monotonicity gives w(y) = F(⊥, y) ≤ c ≤ F(x, ⊤) = v(x) with c = F(⊥, ⊤) the corner. The signatures are therefore forced by c's position. On Ω × Ω:
- At an interior corner, v and w take finitely many values, and all escape lies in strips Ω × [a, b] or [a, b] × Ω.
- At c = (⊤, ⊥), every value lies in a finite interval [a(y), ⊤] × [⊥, b(x)]. The two coordinates decouple: the column fixes the first, the row the second. But infinitely many such intervals occur.

**3. The two-sided reset** (`lean/Mordor/TwoSided.lean`, standard axioms only).
- `reset_core_dual` resets columns to meets of co-anchor columns, the order dual of `reset_core`. `reset_core` now also records that anchor rows are unchanged.
- **`two_sided`.** On a lattice with finitely many hubs and finitely many co-hubs, reset rows with anchors {⊥} ∪ hubs, then columns with co-anchors {⊤} ∪ co-hubs. Under no witness the result G is monotone and witness-free, and every value lies in an interval [w, v] where:
  - w = G(⊥, y) ≠ ⊥ ranges over a finite set W: meets of bottom-row values, or the ideal of a non-co-hub;
  - v = G(x, ⊤) ≠ ⊤ ranges over a finite set V: joins of anchor values, or the filter of a non-hub.
- **`cut_two_sided`.** If moreover all intervals [w, v] with ⊥ < w ≤ v < ⊤ are finite, every cut has a witness.
- **`cut_two_sided_capture`.** It is enough that each infinite such interval lies inside D (v ∈ D) or inside U (w ∉ D). Its values are then captured by v, respectively w. **The only obstruction left is a cut that *crosses* an infinite interval: w ∈ D, v ∉ D.**

**Application to Ω × K, K finite** (lattice facts checked on truncations, `experiments/products/strips_check.py`):
- The hubs are (⊥, k) and the co-hubs (⊤, k), so `two_sided` applies.
- The infinite intervals [w, v] with ⊥ < w ≤ v < ⊤ are exactly the strips [(⊥, k), (⊤, k′)] with ⊥ < k ≤ k′ < ⊤ in K:
  - Ω × C₃: only [(⊥,1), (⊤,1)];
  - Ω × C₄: [1,1], [1,2] and [2,2];
  - Ω × M₃: one strip per atom.
- So **Cut holds on Ω × K for every cut that crosses no strip**. On Ω × C₃: for every cut except those with (⊥, 1) ∈ D ∌ (⊤, 1).

**The crossing case on Ω × C₃** (hand argument, not formalized). Write D̂ = {a : (a, 1) ∈ D}, a proper cut of Ω. Suppose the reset G has G((⊥,1), ⊤) = (⊤, 1) and G(⊥, (⊤,1)) = (⊥, 1).
- Every row (a, 1) with a ∈ D̂ then has G((a,1), ⊤) = (⊤, 1); every column (b, 1) with b ∉ D̂ has G(⊥, (b,1)) = (⊥, 1).
- So the slice cells ((a,1), (b,1)) take values (p, 1) with second coordinate exactly 1.
- The slice problem Ĥ(a, b) = π₁ G((a,1), (b,1)) on Ω with cut D̂ has a witness, since Ω is end-finite (`cut_of_end_finite`). It lifts, because the value's second coordinate is 1.

Here, unlike the general products of §34.3u, slice witnesses do lift: strip confinement pins the second coordinate. What remains open is the sub-case where the bottom strip row or the top strip column leaves the strip. There the slice values can have second coordinate 0 or 2, and the projection loses the witness.

**Assessment of the proposal.**
- *Pin signatures:* correct, and sharper in the corner-sandwich form above.
- *Finite-fibre theorem:* the right target. It is now reduced in Lean to crossing strips, and for Ω × C₃ to one sub-case.
- *Paired rank:* the natural measure for iterating `two_sided` on strips is the Dershowitz–Manna order on the finite multiset of crossing intervals. It needs a region-relative two-sided reset, whose obstacle is that joins of anchor values leave the region.
- *Counterexample search:* by the fold remark of §34.3u, any branch-shifting scheme must be aperiodic.

## 34.3x New: CL on L × C₃ for every end-finite L (Ω × C₃ settled)

The crossing case left by §34.3w closes. `lean/Mordor/Strip.lean`, standard axioms only, no truncation evidence needed.

**Theorem** (`Strip.cut_prod_three`, `Mordor.semi_of_prod_three`). Let L be a nontrivial complete lattice whose proper principal ideals and proper principal filters are all finite. Then every cut of every monotone F on L × C₃ has a witness, and semi-CL and CL hold on L × C₃. In particular **Ω × C₃**, the smallest open case of §34.3w, satisfies CL.

**The mechanism: one crossing strip** (`cut_one_strip`, `semi_of_one_strip`). Hypotheses:
- finitely many hubs and co-hubs;
- every infinite interval [w, v] with ⊥ < w ≤ v < ⊤ lies inside one interval [s, t];
- [s, t] is relatively end-finite;
- [s, t] satisfies the modularity condition "(g ⊓ t) ⊔ s = s and (g ⊔ s) ⊓ t = t never hold together".

Then Cut holds. The proof runs the two-sided reset (§34.3w).
- *No crossing.* `cut_two_sided_capture` applies.
- *Crossing* (s ∈ D, t ∉ D). Three lemmas:
  - **`core_finite`.** On core cells (x ≥ s, y ≤ t), a value z ∈ [s, t] lies below m = G(x, t) ⊓ t ≠ t (else (x, t) is a witness) and above n = G(s, y) ⊔ s ≠ s. Also m ≥ (G(s, t) ⊓ t) ⊔ s and n ≤ (G(s, t) ⊔ s) ⊓ t. By the modularity condition one of these two corner bounds is proper, and relative end-finiteness then leaves finitely many core values. This is the end-finite argument with s as a soft bottom and t as a soft top.
  - **`strip_contra`.**
    - *Off the core a strip value cannot be part of a witness:* z ≤ x forces x ≥ s, and y ≤ z forces y ≤ t.
    - *Lower or raise them:* where x ≱ s, lower z to s ⊔ ⋁{outside values ≤ z}; where x ≥ s and y ≰ t, raise it to t ⊓ ⋀{outside values ≥ z}. The result is still monotone on the cells D × U and witness-free, and now has finitely many values, because the values outside [s, t] are finitely many: they lie in finite intervals.
    - *No crossing hypothesis needed:* the lemma does not even use s ∈ D or t ∉ D.
  - **`extend_mono`.** A bifunction monotone on D × U extends to a globally monotone one with the same cell values, via F′(x, y) = ⋁{F(x′, y′) : x′ ≤ x, y′ ≤ y, (x′, y′) a cell}. So `cut_of_values_in_finite` applies.

For L × C₃ (`cut_prod_three`) take s = (⊥, 1) and t = (⊤, 1). Each hypothesis follows from end-finiteness of L:
- hubs ⊆ {⊥} × C₃ and co-hubs ⊆ {⊤} × C₃;
- an infinite interval needs first coordinates ⊥ and ⊤, hence second coordinates in [1, 1];
- [s, t] ≅ L is relatively end-finite;
- the modularity condition reduces to ⊥ ≠ ⊤ in L.

**Scope.** One strip covers exactly the fibres K whose middle K ∖ {⊥, ⊤} is a single element. The next cases:
- K = M_n (middle an antichain) gives several pairwise incomparable strips. A multi-strip version (crossing strips modified, non-crossing ones captured) should handle these.
- K = C₄ gives nested strips [1,1], [1,2], [2,2]. Their union [(⊥,1), (⊤,2)] ≅ L × C₂ is not relatively end-finite, so this needs recursion.
- Ω × Ω, and finite posets, remain open.

## 34.3y New: several separated strips — CL on L × Mₙ

`lean/Mordor/Strips.lean`, standard axioms only.

**`cut_strips`.** Hypotheses:
- finitely many hubs and co-hubs;
- every infinite interval [w, v] with ⊥ < w ≤ v < ⊤ lies in one of finitely many strips [s, t];
- each strip is relatively end-finite and modular at s, t;
- the strips are *separated*: no element of one strip lies below an element of another.

Then Cut holds. The proof runs §34.3x's argument on all strips at once.
- **Crossing strips** (s ∈ D, t ∉ D) are lowered or raised to finitely many values. The guide posts are the finitely many values outside every strip. Separation guarantees that a value in one strip is never compared with a value in another, so one finite set of guide posts serves all crossing strips (`pick` selects a value's unique strip).
- **Non-crossing strips** keep their values, which may be infinitely many. They are captured by t when t ∈ D, and by s when s ∉ D. `capture_contra` on the monotone extension (`Strip.extend_mono`) then closes the proof.

**Corollary** (`cut_prod_antichain`, `Mordor.semi_of_prod_antichain`). Let L be a nontrivial complete lattice with finite proper principal ideals and filters, and K a finite complete lattice whose middle K ∖ {⊥, ⊤} is an antichain (K = Mₙ; C₃ = M₁). Then Cut and CL hold on L × K. The strips are [(⊥, k), (⊤, k)], one for each middle element k:
- separation is exactly the antichain condition;
- each strip is ≅ L, hence relatively end-finite;
- the modularity condition reduces to ⊥ ≠ ⊤ in L.

**Examples:** Ω × M₃, Ω × M_n.

**Still open:**
- **Ω × C₄**, the first fibre K with comparable middle elements. Its infinite intervals [1,1], [1,2], [2,2] are nested, not separated, and their union [(⊥,1), (⊤,2)] ≅ L × C₂ is not relatively end-finite. Inside that union, the would-be relative strips [(⊥,2), (⊤,1)] are empty. This suggests a recursion depth of one: a two-sided reset relative to the core of [(⊥,1), (⊤,2)], whose only escapes are the finitely many values outside it.
- Ω × Ω.
- Finite posets.

## 34.3z Outside proposals read again; L × C₄ reduced to one configuration

A second outside review (fresh session) proposed four directions. Checked:

**1. Finite-support crossing.** The finite-support lemma (ACC ⟹ every supremum is attained on a finite subset) is Mathlib's `WellFoundedGT.isSupFiniteCompact`. `wellFoundedGT_iff_isSupFiniteCompact` shows it is in fact *equivalent* to ACC. Its consequence is correct: if box cells (x_i, y_i) have values with ⋁ z_i = t, then x* = ⋁ x_i ∉ D, else (x*, ⋁ y_i) is a witness. But it constrains only realized values, and only through join-closure. It is the join gap of §31.1 (R(F) join-closed) seen from one box, so it adds no new lever. The proposed "finite crossing lemma" is the open problem itself.

**2. Capture-or-ratchet.** A finite table, a pivot, and a well-founded rank on the active boundary: this is exactly the architecture of `IdealFinite.key`, with Dershowitz–Manna on region generators (§34.3t). The missing piece the proposal names, a rank once boundaries are infinite in both directions, is the frontier.

**3. L × C₄ (the recommended intermediate target).** Worked by hand; *not formalized*. Write s_k = (⊥, k), t_k = (⊤, k), and S_k = [s_k, t_k] ≅ L for the strips. After the two-sided reset, every infinite interval lies in S₁ ∪ S₂. Cuts with s₁ ∉ D or t₂ ∈ D cross nothing (§34.3w). Otherwise there are three configurations:
- **(B) only S₁ crossed** (s₂ ∉ D, so S₂ ⊆ U). *Wall argument:*
  - Every column y ≰ t₁ satisfies y ≥ s₂ ∉ D. So a value z ∈ S₁ at a cell with x ≥ s₁ and y ≰ t₁ lies above δ = G(s₁, s₂), and δ ≰ s₁ forces δ₁ ≠ ⊥. Hence z ∈ ↑δ ∩ S₁, a finite set.
  - These values therefore need no inflation. The values in S₁ at core cells are finite (`core_finite`), and the values at cells x ≱ s₁ are lowered as in §34.3x.
  - S₂ is captured by s₂. Every other value lies in a finite interval.
- **(C) only S₂ crossed** (t₁ ∈ D, so S₁ ⊆ D). Symmetric: the row wall t₁ ∈ D lies above every row x ≱ s₂.
- **(B∧C) both crossed**, i.e. s₁, s₂ ∈ D and t₁, t₂ ∉ D. Remains open. Lowering and raising per strip conflict only on cells with x₂ = 1 and y₂ = 2.
  - There a lower-strip value needs to stay ≰ x, an upper-strip value needs to stay ≱ y, and neither wall applies.
  - *Rigorous negative remark:* no pair of value maps fixes this. Take u inflationary on S₁ and d deflationary on S₂ with u(z) ≤ d(z′) whenever z ≤ z′. The pair z = (a, 1), z′ = (a, 2) forces u(a, 1) = (a, 1) for every such a, so u cannot have finite image. Decoupling nested strips must use the cells, not just the values.
  - The configuration is a coupled "thick cut" between layer 1 (rows: D̂₁) and layer 2 (columns: the complement of D̂₂), with D̂₂ ⊆ D̂₁, where D̂_k = {a : (a, k) ∈ D}.

So L × C₄ is reduced to the cuts with s₁, s₂ ∈ D and t₁, t₂ ∉ D (hand argument for (B) and (C); formalizing would need a multi-strip variant with walls).

**4. Counterexample search on Ω × Ω.** Agreed as a stress test. By the fold remark (§34.3u) a counterexample must be aperiodic, and on any Ω × K for finite K it must cross nested strips (§34.3y). The thick-cut configuration above is the first place where a branch-shifting pattern is not yet ruled out.

## 34.3z′ L × C₄, doubly crossed cuts: what is known, what fails

Hand analysis, *not formalized*. Notation: s_k = (⊥, k) and t_k = (⊤, k); S_k = [s_k, t_k] ≅ L; D̂_k = {a : (a, k) ∈ D}. The open configuration of §34.3z is s₁, s₂ ∈ D and t₁, t₂ ∉ D, with G the two-sided reset.

**1. Localization to one block of cells (holds).** Give the strip modifications of §34.3x–y one common finite guide set: the values outside S₁ ∪ S₂, plus the core values of S₁ and of S₂. All of these are finite. The modification:
- lower values in S₁ where x₂ = 0;
- raise them where x₂ ≥ 1 and y₂ ≥ 2, except at cells with x₂ = 1 and y₂ = 2;
- lower values in S₂ where x₂ ≤ 1 and y₂ ≤ 2, except at those same cells;
- raise them where y₂ = 3;
- leave the remaining harmless values unchanged at first, then lower or raise them in the same way.

A raised value lies below a lowered one at comparable cells only when both cells have x₂ = 1 and y₂ = 2. So, keeping the values on

  **Q = {cells with x₂ = 1, y₂ = 2}**

unchanged, the result is monotone on cells, witness-free, and has finitely many values outside Q. On Q only two kinds of value can take part in a witness:
- values in S₁ ∩ D, which can lie below the row;
- values in S₂ ∩ U, which can lie above the column.

Values in S₁ ∩ U and S₂ ∩ D are harmless there. **A counterexample on L × C₄ must therefore carry infinitely many such values on Q**, whose rows are D̂₁ × {1} and whose columns are (L ∖ D̂₂) × {2}.

**2. Value maps cannot finish Q (holds).** Raise the values in S₁ ∩ D and lower those in S₂ ∩ U by maps u, d with finite images. Then u(a, 1) ≤ d(b, 2) is needed for every comparable pair of values (a, 1) ≤ (b, 2) on comparable cells of Q, with a ∈ D̂₁ and b ∉ D̂₂.
- With a common finite guide set this requires a finite Γ ⊆ L separating every such pair: a ≤ γ ≤ b for some γ ∈ Γ.
- In Ω no such Γ exists once D̂₂ meets infinitely many chains, since each chain needs its own separator.
- This holds *even when the cut is not thick* (D̂₁ = D̂₂). §34.3z located the conflict only at thick elements; in fact it occurs at all such pairs.

Q needs an argument that uses the cells. For non-thick rows and columns the walls x⁺ = (x₁, 2) ∈ D and y⁻ = (y₁, 1) ∉ D sandwich Q values between values at core cells. But the upper bound G(x⁺, y) can itself be an unbounded value in S₁, or t₁. So the sandwich does not close.

**3. The box cannot be cut out (holds).** Every strip value lies in the box [s₁, t₂] ≅ L × C₂, and box cells take only finitely many values outside it ("escapes"). L × C₂ satisfies Cut (§34.3y with K = C₂), but a box-with-escapes lemma is **false**. Take any escape e ∈ D with e ∨ s₁ ∉ D, put it at every box cell, and the box has no witness:
- e ≤ x would force e ∨ s₁ ≤ x ∈ D;
- y ≤ e is impossible since e ∈ D.

So the contradiction must use cells outside the box. This is the join gap (§31.1) in finite form: e ∨ s₁ leaves D.

**4. Evidence for truth.** Two hand attempts at a counterexample on Ω × C₄ with a thick cut (D̂₂ = {⊥}, D̂₁ = {⊥} ∪ atoms) each died on an end-finite slice argument:
- The only upper row s₂ must avoid witnesses on the box [s₂, ⊤] ≅ Ω × C₂, which Cut on Ω × C₂ forbids.
- Column (⊤, 0) forces a monotone map on Ω ∖ {⊤} with g(c) ≰ c, impossible in Ω, since it fails at the top of the chain containing g(⊥).

Status: L × C₄ is open exactly for doubly crossed cuts. A proof has to handle the block Q with cell-dependent modifications, or with a parity argument on a finite table that also contains cells outside [s₁, t₂].

*Resolved in §34.3z″:* the corner G(s₁, t₂) decides Q, and a down-closed zone rule replaces the strip modifications altogether.

## 34.3z″ New: CL on L × K for every finite K — the corner lemma (Ω × C₄ settled)

Prompted by an outside research brief (sixth round) whose main question was: *what mechanism makes the infinitely many dangerous values on the block Q contradictory, now that finite capture, independent strip resets and box localization are exhausted?* The brief asked for a cell-dependent argument that uses cells outside the box. The answer is short, needs neither the reset nor strips, and covers every finite fibre. `lean/Mordor/Layers.lean`, standard axioms only.

**Theorem** (`Layers.cut_prod_finite`, `Mordor.semi_of_prod_finite`). Let L be a complete lattice whose proper principal ideals and filters are finite (e.g. Ω), and K any finite complete lattice. Then every cut of every monotone F on L × K has a witness, so semi-CL and CL hold on L × K. This subsumes L × C₃ (§34.3x) and L × Mₙ (§34.3y), and settles **Ω × C₄**, Ω × Bₙ, Ω × N₅, and so on.

Write s_k = (⊥, k) and t_k = (⊤, k). Suppose F has no witness for D.

**1. Corner lemma.** Let (x, y) ≤ (x′, y′) be cells with values z = F(x, y) and z′ = F(x′, y′). Suppose z₂ ≤ x₂ (so s_{z₂} ≤ x) and y′₂ ≤ z′₂ (so y′ ≤ t_{z′₂}). Put k = z₂, k′ = z′₂ and h = F(s_k, t_{k′}). Both s_k ∈ D and t_{k′} ∉ D hold, so (s_k, t_{k′}) is a cell.
- h₁ ≠ ⊤. Otherwise r = F(x′, t_{k′}) ≥ h has r₁ = ⊤, and r ≥ z′ gives r₂ ≥ k′. So t_{k′} ≤ r, a witness.
- e = F(s_k, y) has e₁ ≠ ⊥. We have e ≤ z, so e₂ ≤ k. If also e₁ = ⊥, then e ≤ s_k, a witness.
- Since e ≤ h and e ≤ z, z₁ ∈ ↑e₁ with e₁ ∈ ↓h₁ ∖ {⊥}.

So z lies in the finite set Γ = ⋃_{k,k′ ∈ K} {w : ∃ e ≠ ⊥, e ≤ F(s_k, t_{k′})₁, e ≤ w₁} (taken over the pairs with F(s_k, t_{k′})₁ ≠ ⊤). Γ is fixed before any modification. Only the case k = k′, c = d appeared before, as `core_finite`.

**2. Zones from cells.** A value z ∉ Γ at a cell may be lowered to λ(z) = s_{z₂} ⊔ ⋁{γ ∈ Γ : γ ≤ z} when z₂ ≰ x₂: then λ(z) ≥ s_{z₂} is not below x, and λ(z) ≤ z is not above y. It may be raised to ρ(z) = t_{z₂} ⊓ ⋀{γ ∈ Γ : γ ≥ z} when y₂ ≰ z₂. The choice:

  **lower z at (x, y) iff some cell (x′, y′) ≥ (x, y) carries a value z′ ∉ Γ with y′₂ ≤ z′₂.**

- *Lowered cells form a down-set,* so a raised value never lies below a lowered one.
- *Lowering is legal.* If z₂ ≤ x₂, the corner lemma puts z in Γ.
- *Raising is legal.* If y₂ ≤ z₂, the cell itself triggers lowering.
- *Monotone.* Values in Γ are left alone and act as guide posts. λ and ρ are monotone, and λ ≤ id ≤ ρ.
- *Finitely many values.* The values of λ and ρ are the joins s_k ⊔ ⋁Q and the meets t_k ⊓ ⋀Q, with k ∈ K and Q ⊆ Γ.

`Strip.extend_mono` and `Pin.cut_of_values_in_finite` finish. With K trivial this is `cut_of_end_finite`.

**What the brief's directions became.**
- *Direction 1 (cell-dependent argument on Q):* this is it. On §34.3z′'s block Q the corner is G(s₁, t₂), and its first coordinate decides the case. If it is ⊤, Q carries no S₂ values. If it is ⊥, Q carries no S₁ values. Otherwise Q carries finitely many strip values. The rows and columns used, s₁ and t₂, lie outside Q, as the brief anticipated.
- *Direction 3 (coupled reset):* the zone rule is the coupling. Strips, crossing and capture all drop out. The only coupling needed is that the lowered cells are closed downward. By an exhaustive SAT check over all cut types (`experiments/products/zones_check.py`), zones that depend only on the layers (x₂, y₂) and use the pairwise box exemption are infeasible already for C₅. Zones that depend on the corners of G succeed for C₃–C₆ (`zones3.py`). The down-closure rule above is what that search pointed to, and it needs no case analysis at all.
- *Directions 2 and 4 (Sperner tables, minimal counterexample to join-closure):* not needed for products with a finite factor. They remain the candidates for the general frontier.

**Finitely many layers in use is enough.** The proof uses finiteness of K only through the layers z₂ of values. `Layers.cut_prod_layers` takes any complete K and assumes, under no witness, that cell values have second coordinates in a finite set. This is the form to aim at for Ω × Ω.

**Ω × Ω: where it stands** (hand analysis, not formalized). Run the same construction with the roles of the coordinates exchanged:
- lower to (z₁, ⊥) ⊔ ⋁{γ ≤ z} and raise to (z₁, ⊤) ⊓ ⋀{γ ≥ z};
- take the guide set Γ′ to be all corner-lemma outputs, now an infinite union.

Joins and meets over Γ′ still exist, and monotonicity and witness-freeness go through unchanged. If the corner family

  {F((k, ⊥), (k′, ⊤))₂ : (k, ⊥) ∈ D, (k′, ⊤) ∉ D} ∖ {⊤}

is finite, the second coordinates of the guides lie in a finite set. Then so do the second coordinates of all modified values, and `cut_prod_layers` finishes. Symmetrically for the family F((⊥, k), (⊤, k′))₁. **A counterexample on Ω × Ω therefore needs both corner families infinite.** *(Superseded by §34.3z‴: one family is always bounded, and Ω × Ω satisfies CL.)* That means F must move the anchors (k, ⊥), (⊤, k′) diagonally, so that corners track the anchors' own coordinates. This is the next target, from either side.

## 34.3z‴ New: CL on L₁ × L₂ for any two end-finite lattices (Ω × Ω settled)

Prompted by an outside brief (seventh round) proposing three programs for Ω × Ω:
1. branch-switching with Ramsey canonicalization and "rectangle amalgamation";
2. compressing interaction types instead of values;
3. a coupled transition system for the diagonal corner families.

None of the machinery turned out to be needed. The corner families of §34.3z″ are always bounded, through one of two anchors chosen by the position of the single corner F(⊥, ⊤). `lean/Mordor/Plane.lean`, standard axioms only.

**Theorem** (`Plane.cut_prod_end_finite`, `Mordor.semi_of_prod_end_finite`). Let L₁, L₂ be complete lattices whose proper principal ideals and filters are finite. Then every cut of every monotone F on L₁ × L₂ has a witness, so semi-CL and CL hold. In particular **Ω × Ω**, the test case named in §34.3t, satisfies CL. This is the first product theorem for Cut with two infinite factors.

**Ingredients** (all in `Plane.lean`):
- **`zone_lo`, `zone_hi`.** The zone construction of §34.3z″ as an abstract lemma. It takes a guide predicate, lowering and raising maps, the "stuck" predicates, and a corner hypothesis. `zone_lo` lowers below non-guide values that are stuck for raising. `zone_hi` is the dual: it raises above values that are stuck for lowering, and its corner hypothesis makes the *upper* value a guide. Monotonicity of the maps is needed only between comparable non-guide cell values.
- **`cut_prod_layers_fst`.** `cut_prod_layers` with the coordinates exchanged, via `cut_of_swap`.
- **`collapse_lo`.** Suppose every corner F((⊥, k), (⊤, k′)) over the cells has first coordinate ≤ m for a fixed m ≠ ⊤. The corner lemma puts every value that cannot be lowered (in the second-coordinate layers) into S × L₂, where S = ⋃_{e ≤ m, e ≠ ⊥} ↑e is finite. Lowering to (⌊z₁⌋_S, z₂) and raising to (⌈z₁⌉_S, z₂) then leaves finitely many first coordinates. The guide set is infinite, but its first coordinates are finitely many: a finite "interaction type" in the sense of the brief's Strategy 2. `cut_prod_layers_fst` finishes.
- **`collapse_hi`.** The dual: every corner has first coordinate ≥ n ≠ ⊥. The corner lemma's upper half puts the upper value z′ into ⋃_{f ≥ n, f ≠ ⊤} ↓f × L₂, and `zone_hi` is used.
- **`cut_prod_cross`.** Suppose every value lies in a finite set, or in a horizontal strip L₁ × T₂, or in a vertical strip T₁ × L₂, with T₁, T₂ finite sets of middle elements. Horizontal values are lowered and raised in the second-coordinate layers, vertical ones in the first. A horizontal and a vertical non-guide value are never comparable: comparability would put the horizontal one in (↓T₁ ∪ ↑T₁) × T₂, a finite set added to the guides. So one zone rule with type-dependent maps works.

**The case analysis on c = F(⊥, ⊤).** Every value satisfies F(⊥, y) ≤ z ≤ F(x, ⊤), with F(⊥, y) ≤ c ≤ F(x, ⊤), F(⊥, y) ≠ ⊥ and F(x, ⊤) ≠ ⊤.
- *c₁ = ⊥, c₂ ≠ ⊤.* Then F(⊥, y) = (⊥, w₂) with ⊥ ≠ w₂ ≤ c₂, so z₂ ∈ ⋃_{e ≤ c₂, e ≠ ⊥} ↑e, a finite set: `cut_prod_layers`. Symmetrically for *c₁ = ⊤, c₂ ≠ ⊥*, and for the cases with the coordinates exchanged (`cut_prod_layers_fst`).
- *c₁, c₂ both middle.* For each coordinate i, a value has z_i ∈ Lo_i = ⋃_{e ≤ c_i, e ≠ ⊥} ↑e when F(⊥, y)_i ≠ ⊥, and z_i ∈ Hi_i = ⋃_{f ≥ c_i, f ≠ ⊤} ↓f when F(x, ⊤)_i ≠ ⊤. At least one of each pair holds. So z lies in a finite box (Lo ∪ Hi)₁ × (Lo ∪ Hi)₂, or in the horizontal strip L₁ × (Lo₂ ∩ Hi₂), or in the vertical strip (Lo₁ ∩ Hi₁) × L₂: `cut_prod_cross`.
- *c = (⊥, ⊤).* If the element (⊥, ⊤) is in D, it is a row. Every corner satisfies F((⊥, k), (⊤, k′)) ≤ F((⊥, ⊤), ⊤) =: M, and M ≥ c forces M₂ = ⊤, hence M₁ ≠ ⊤: `collapse_lo` with m = M₁. If (⊥, ⊤) ∉ D, it is a column. Every corner of the other orientation satisfies F((k, ⊥), (k′, ⊤)) ≥ F(⊥, (⊥, ⊤)) =: N, and N ≤ c forces N₁ = ⊥, hence N₂ ≠ ⊥: `collapse_hi` on the swapped product with n = N₂.
- *c = (⊤, ⊥).* Symmetric, through the anchor (⊤, ⊥).

**The brief's programs, in this light.**
- *Strategy 1 (rectangle amalgamation).* As stated it cannot work from monotonicity alone. The mixed cell (x₁ ∧ x₂, y₁ ∨ y₂) is comparable to neither (x₁, y₁) nor (x₂, y₂); it lies above (x₁ ∧ x₂, y_i) and below (x_i, y₁ ∨ y₂). Any amalgamation therefore has to pass through values at further cells. In the proof that role falls to the fixed anchors (⊥, ⊤) and (⊤, ⊥), which are where cross-branch meets and joins land. No Ramsey thinning is needed, because the corner families are bounded outright, not merely canonicalized.
- *Strategy 2 (profiles).* Realized by `collapse_lo`/`_hi`: the guide set is S × L₂, infinite, but the modification reads only ⌊z₁⌋_S and ⌈z₁⌉_S, which take finitely many values. This is the "generalization of `cut_prod_layers` to finitely many interaction types" the brief asked for. The finite type is the first coordinate's floor or ceiling in S.
- *Strategy 3 (diagonal dynamics).* The diagonal obstruction of §34.3z″ was an artefact of looking at the corner families without the anchor (⊥, ⊤). Once c is (⊥, ⊤) or (⊤, ⊥), that anchor bounds one family, as a row or as a column, so no recurrence or escape analysis arises.

**An eighth outside brief** was written against `dcec27d`, before this section. Its Programs 1–3 (homogeneous defects, loop certificates, finite-cover versus infinite-matching) all target "both corner families infinite and diagonally coupled". By the case analysis above that configuration does not arise: when c ∉ {(⊥, ⊤), (⊤, ⊥)}, no corner family is needed at all, and when c = (⊥, ⊤) or (⊤, ⊥), one family is bounded through that anchor. Its Program 4 asks for a bridge from stabilization of the orbit r_n to join-closure of R(F). That bridge is the frontier statement itself (`cutMaps_iff_joinClosed`, §34.4a). The extra lever `orbit_tight` needs top-closedness, which fails already on Ω × Ω: D = ↓(a, ⊥) ∪ ↓(⊥, b), with a, b in the middle, misses its join (a, b) ≠ ⊤. On a top-closed lattice, two incomparable elements always join to ⊤, so there the bridge only says that ⊤ ∈ R(F) as soon as R(F) contains two incomparable elements. That is a restatement, not a new route.

**Next frontier.** Ω × Ω × Ω, and more generally products in which one factor is not end-finite: the case analysis uses end-finiteness of *both* factors for the sets Lo and Hi. Beyond products: chain-finite lattices with infinite proper principal ideals and filters, not covered by the box criterion.

## 34.3z⁗ Ω³: where the plane argument stops (hand analysis, ninth outside brief)

A ninth outside brief, written against `0dacf0c`, proposed four programs:
1. a three-coordinate corner calculus for Ω³;
2. face transfer and cube consistency;
3. a finite-separator theorem for unresolved boxes;
4. common-guide gluing.

Checking Program 1 against `Plane.lean` shows why the two-factor proof does not iterate, and isolates the lemma that every route to Ω³ goes through. None of this is formalized.

**1. The corner lemma needs a one-dimensional fibre.** Take fibre coordinates C and keep the rest as layers. For a stuck pair (z below z′), the corner argument gives e ≤ z with e_C ≠ ⊥_C and h ≥ e with h_C ≠ ⊤_C. If |C| = 1 these are the same coordinate, and z_C ∈ ↑e_C with e_C ∈ ↓h_C is finite. If |C| ≥ 2 they can be different coordinates: e = (e₁, ⊥, ·) and h = (⊤, h₂, ·) bound nothing. So every collapse step must flatten one coordinate at a time, keeping all the others as layers.

**2. Slabs of different orientation meet in lines.** On Ω³ the sandwich F(⊥, y) ≤ z ≤ F(x, ⊤) through c = F(⊥, ⊤) pins a coordinate of each value only cell by cell. These are the brief's nine defect labels. For instance, with c = (⊥, c₂, c₃) and c₂, c₃ ≠ ⊤, each value has z₂ ∈ Lo₂ or z₃ ∈ Lo₃, depending on the cell. In `cut_prod_cross` a horizontal and a vertical value were comparable only inside a finite set. In three dimensions, z₁ ∈ T₁ and z ≤ z′ with z′₂ ∈ T₂ only gives z ∈ T₁ × ↓T₂ × L₃, an infinite line. The cross theorem does not lift.

**3. Every route funnels into one lemma.** The signatures c = (⊥, ⊥, c₃) with c₃ ≠ ⊤, and (⊤, ⊤, c₃) with c₃ ≠ ⊥, and their permutations, pin one coordinate of every value to a finite set. Collapsing the Ω-coordinate of Ω × Ω² (`collapse_lo` with fibre Ω and layers Ω²) does the same. Both leave

  **(G1)** Cut on L₁ × L₂ × K, with L₁, L₂ end-finite and K arbitrary, when the cell values have K-coordinates in a finite set:

the plane theorem relative to finitely many layers, as `cut_prod_layers` is `cut_of_end_finite` relative to finitely many layers. The mixed signatures need G1 several times at once, glued along slabs.

**4. What G1 has to handle (K = C₂).** Lowering and raising in the K-coordinate are legal for every value except those *stuck on both sides* (z₃ ≤ x₃ and y₃ ≤ z₃). By the layers (x₃, y₃) of the cell, these are:
- the two core regions: (0, 0) with z₃ = 0, and (1, 1) with z₃ = 1;
- the whole thin region (x₃, y₃) = (1, 0).

In each region the no-witness condition reduces to one on the projection to L₁ × L₂. Examples: at (1, 0), z ≤ x iff (z₁, z₂) ≤ (x₁, x₂), and y ≤ z iff (y₁, y₂) ≤ (z₁, z₂). So these are slice problems whose witnesses lift (the brief's face transfer holds exactly there). But the thin region's rows D̂₁ and columns L∖D̂₀ do not form a cut. A thin "cut" has no Cut lemma by itself: on C₃ with rows {0}, columns {2} and F(0, 2) = 1 there is no witness. So the slices cannot be settled one at a time. For each layer pair (k, k′) the stuck pairs sit in the box s_k ≤ x, y′ ≤ t_{k′}, with s_k = (⊥, ⊥, k) and t_{k′} = (⊤, ⊤, k′). There they obey the plane sandwich e ≤ z ≤ z′ ≤ r with e_{12} ≠ ⊥, r_{12} ≠ ⊤, and corner h(k, k′) = F(s_k, t_{k′}). So each of the finitely many layer pairs falls into one of the plane theorem's cases: box or strips, a pinned coordinate, or anti-diagonal. The open step is to choose one zone rule for all pairs at once. This is the brief's "cube consistency" (Program 2), made concrete.

**Programs 3–4** (box separators, common guides for general chain-finite lattices) need a well-founded refinement measure that the brief does not supply. Not pursued.

**Next target:** G1 for K = C₂, i.e. Ω × Ω × C₂, then G1 in general, then Ω³ by gluing slabs.

## 34.3z⁵ G1: the layer pass, and what is left (anti-diagonal boxes)

Work towards G1 (§34.3z⁗): Cut on Π × K, with Π = L₁ × L₂ end-finite and the values' K-coordinates in a finite set T.

**1. The layer pass** (`lean/Mordor/KPass.lean`, `KPass.kpass`, standard axioms; any complete Π, K). Call a value z at (x, y) *K-lowerable* if z₂ ≰ x₂ in the layer coordinate, and *K-raisable* if y₂ ≰ z₂.
- **The pass.** Lower to (⊥, z₂) every cell all of whose lower cells carry K-lowerable values. Raise to (⊤, z₂) every remaining cell all of whose upper cells carry K-raisable values. Keep the rest.
- **What it gives.** The result is monotone and witness-free on cells, so the zone lemma is not needed for this step. Every kept value z lies in a **plane sandwich** e ≤ z ≤ r, e ≤ h ≤ r, with e_Π ≠ ⊥ and r_Π ≠ ⊤, around a **base corner** h = F((⊥, k), (⊤, k′)), where k, k′ are layers of cell values.
- **Why.** A kept cell has a stuck-lo cell below it and a stuck-hi cell above it; their anchors give e and r.

So all the infinitely many values that remain sit around finitely many base corners, as all values of the plane theorem sat around the single corner F(⊥, ⊤). When T is a chain, choosing k as the largest stuck-lo layer below the cell and k′ as the smallest stuck-hi layer above it makes the corner a **monotone function of the cell**.

**2. One layer.** |T| = 1 is a slice. With all values in layer t:
- if (⊥, t) ∉ D or (⊤, t) ∈ D there is a trivial witness;
- otherwise F̂(p, q) = π F((p, t), (q, t)) on Π with the cut D̂_t has a witness by `cut_prod_end_finite`, and it lifts because the layer is pinned.

**3. No anti-diagonal corner: G1 holds (hand argument, not formalized).** Classify each kept value by the Π-class of its base corner h. The classes (⊥, ⊥) and (⊤, ⊤) are impossible, because e_Π ≠ ⊥ and r_Π ≠ ⊤.
- **h₁, h₂ both middle:** as in the plane theorem, the value lies in a finite box, or has z₂ in a finite set of middle elements, or z₁ in one.
- **h = (⊥, middle):** e₁ = ⊥ forces e₂ ≠ ⊥, so z₂ ∈ Lo₂(h₂). This set avoids ⊥ but may contain ⊤.
- **h = (⊤, middle):** r₁ = ⊤ forces r₂ ≠ ⊤, so z₂ ∈ Hi₂(h₂). This set avoids ⊤ but may contain ⊥.
- **h = (middle, ⊥) or (middle, ⊤):** symmetric, giving vertical families.

Now run one zone pass with two types:
- horizontal values: lower to (⊥, z₂, z₃) ⊔ guides, with corner lemma fibre L₁;
- vertical values: lower to (z₁, ⊥, z₃) ⊔ guides, with corner lemma fibre L₂.

Mixed comparable pairs are handled as follows.
- **Pairs caught by a finite set.** A horizontal z ≤ a vertical z′ puts z in ↓T₁ × T₂ × T when z′₁ ≠ ⊤, and z′ in T₁ × ↑T₂ × T when z₂ ≠ ⊥. Both sets are finite and join the guides. The case vertical ≤ horizontal is symmetric.
- **The leftover pairs.** These are z₂ = ⊥ below z′₁ = ⊤, and dually z₁ = ⊥ below z′₂ = ⊤. For them, lowering and raising are monotone automatically: (⊥, ⊥, ·) ⊔ g ≤ (⊤, ⊥, ·) ⊔ g′, and (⊤, ⊥, ·) ⊓ g ≤ (⊤, ⊤, ·) ⊓ g′.
- **Their stuck pairs.** These sit around the base corner G((⊥, ⊥, z₃), (⊤, ⊤, z′₃)), where z₂ = ⊥ forces e₁ ≠ ⊥ and z′₁ = ⊤ forces r₂ ≠ ⊤. That corner is not anti-diagonal, so either h₁ ≠ ⊤, which puts z in the finite set Lo₁(h₁) × {⊥} × T, or h₂ ≠ ⊥, which puts z′ in the finite set {⊤} × Hi₂(h₂) × T. Both sets are guides.

So the zone lemma applies and the values become finite.

**4. What is left: anti-diagonal boxes.** Suppose T is a chain, so the corner map is monotone. The cells with corner class (⊥, ⊤) then form a convex set A. Below A there are only (⊥, middle) cells, carrying horizontal values; above A only (middle, ⊤) cells, carrying vertical values. Dually for (⊤, ⊥). Inside A, the plane theorem would collapse one coordinate globally:
- collapsing coordinate 1 (keep z₂, floor z₁) is compatible with the horizontal values below A, but not with the vertical values above it;
- collapsing coordinate 2 is the reverse.

The plane theorem's anchor (⊥, ⊤) becomes the layered anchor a = (⊥, ⊤, k), which can **escape in the layer**. If a ∈ D, M = F(a, (⊤, ⊤, k′)) ≥ h has M₂ = ⊤. But witness-freeness only gives M₁ ≠ ⊤ *or* k′ ≰ M₃. In the second case M = (⊤, ⊤, m₃) with m₃ < k′, and no coordinate is bounded. Such an escape points to the smaller layer pair (k, m₃). This suggests recursion on layer pairs, well-founded because T is finite, but it is not yet made into a proof.

**Next:** make the layer-escape recursion precise for T = {0, 1}, the first case where the anti-diagonal box can sit between a horizontal and a vertical region.

## 34.4 The dialgebra and duality theorems (§32, §33.3)

`Mordor/Dialgebra.lean` proves four results:
- **Transposition:** the least (f, g)-dialgebra is μ(l∘f) when l ⊣ g, and dually the greatest is ν(r∘g) when f ⊣ r.
- **Failure-zone theorem:** for g preserving binary meets, δ₀ is iso iff f(A₀) ∈ Im g. It needs only a meet-semilattice and monotone f.
- **The dual failure-zone theorem.**
- **D5:** order reversal sends the least (f, g)-dialgebra of α to the greatest (gᵒᵈ, fᵒᵈ)-dialgebra of αᵒᵈ.

`Mordor/Orbit.lean` proves three results for the two orbits R₀ = ↓⊥, R_{k+1} = ↓(R_k ∪ a(R_k) ∪ b⁻¹(R_k)) and r₀ = ⊥, r_{k+1} = r_k ∨ a(r_k) ∨ ⋁{y : b(y) ≤ r_k}:
- **`step_lax`:** the lax square, ⋁Θ⁺(D) ≤ κ⁺(⋁D) for every set D.
- **`orbit_lax`:** consequently ⋁R_k ≤ r_k.
- **`orbit_tight`:** ⋁R_k = r_k for every k and every F, on any complete lattice that is top-closed. Here top-closed means every down-set containing ⊥ that misses its own join has join ⊤. No finiteness is needed.

`Mordor/CutDuality.lean` proves the adjunction Φ(D) ∩ U = ∅ ⟺ D ∩ Ψ(U) = ∅ and the k + j law Φᵏ(D) ∩ Ψʲ(U) = ∅ ⟺ D ∩ Ψᵏ⁺ʲ(U) = ∅ ⟺ Φᵏ⁺ʲ(D) ∩ U = ∅. It does so for **any preorder and arbitrary maps a, b**. §33.3 assumed monotone a, b on a finite lattice, and neither assumption is used. So the per-F self-duality of the Cut Lemma also holds on infinite lattices, including D_ω and E_ω.

## 34.4a The frontier, formally (`Frontier.lean`)

```
theorem frontier :
  (CL on L → every chain of L is finite) ∧
  (every chain of L is finite → (∀ F, R(F) join-closed) → CL on L)
```

The first conjunct is Theorem A. The second chains together chain-finite ⟹ ACC + DCC (`wellFoundedGT_of_chainFinite`, `wellFoundedLT_of_chainFinite`), `cutMaps_iff_joinClosed` and `semi_of_cut`.

With §34.3f, the hypothesis is discharged for edge-height ≤ 3. In general, the program's standing conjecture, "CL holds on every chain-finite complete lattice", is reduced in Lean to one unproved statement: **for every monotone F on a chain-finite complete lattice, R(F) is closed under binary joins.** The same reduction gives the stronger semi-commutation form (`semi_of_joinClosed`). Everything else on both sides of the frontier is checked.

## 34.5 What the formalization says about the program

- **Status of the log's proofs.** Machine-checking six results surfaced one wrong step and one gap. This is the class of error behind the earlier errata (§30.2(ii)'s height claim, the pentagon erratum, the §15.3 existence refinement). Proved results should be formalized when they land, not afterwards.
- **The open problem, sharpened.** §34.2 makes the Cut Lemma for a single F on L itself sufficient for semi-CL, so for CL, on L. Every statement on the route from the Cut Lemma to the Finite Commutation Lemma is now checked. The only unproved link between the program's conjectures and its theorems is the Cut Lemma.
- **Next targets for formalization:**
  - ~~the Cut Lemma at edge-height 4 (E_ω)~~: done by verified ground refutation (§34.3g), and edge-height 5 as well (§34.3h);
  - the two-dimensional failure on 2^ω (§23.3), now also a corollary of Theorem A since 2^ω contains infinite chains;
  - a uniform argument for all finite heights. The certificates of §34.3h share one shape. Under WLOG c ∉ D they descend c_{k+1} = F(⊥, c_k) to the first c_k ∈ D, then iterate rows and columns inside the box (c_k, c_{k−1}), e.g. F(c₁, c), F(F(c₁, c), c), F(c₁, F(c₁, c)). The game the tightness heuristic plays is the prover's side of this iteration, and its length is what a uniform proof must bound.
